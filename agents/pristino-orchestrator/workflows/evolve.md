# EVOLVE Workflow

## Trigger

User requests evolution, enhancement, or "10x" upgrade of an existing artifact.

## Steps

### 1. Baseline Assessment

- Run REVIEW workflow on current artifact (abbreviated)
- Identify current quality score and weakest dimensions
- Understand original intent and constraints

### 2. Define Evolution Target

- Ask: **¿Qué nivel?** (incremental vs. transformational)
- Set target scores per dimension
- Identify what "better" means for this specific artifact

### 3. Improvement Plan

- Map weakest dimensions to specific improvements
- Prioritize: high-impact, low-effort changes first
- Estimate scope: how many iterations needed

### 4. Apply Enhancements

- Execute improvements dimension by dimension
- **Add value**: new insights, ideas, edge cases, trade-offs
- **Remove waste**: redundancies, filler, repetition
- **Resolve ambiguity**: close gaps, improve traceability
- Apply brand voice if user-facing

### 5. Re-Certify

- Score evolved artifact against same 16 dimensions
- Compare before/after scores
- Validate no regression in previously strong dimensions
- Run Adversarial+ if critical

### 6. Deliver Delta

- Present evolved artifact
- Highlight key changes and their rationale
- Show before/after quality comparison

## Evolution Targets

- **10x rule**: Content should be maximally dense — every sentence justifies its existence
- **No inflation**: Evolved artifact should be at most 2x longer, not more
- **Value density**: New content must provide direct practical value

## Failure Handling

- If artifact cannot be improved significantly: report honestly, suggest alternative approaches
- If evolution breaks existing functionality: rollback and iterate more carefully

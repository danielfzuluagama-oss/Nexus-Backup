## Supuestos & Garantías

**Supuestos**:
- Cada bootcamp requiere dedicación 40-50h participante en 3 semanas (no part-time viable)
- Prerequisitos listados son RECOMENDADOS; facilitador adapta si existe skill gap
- Capstone es MVP/demo (no producción-ready; eso es implementación post-bootcamp)
- Precio corporativo incluye customización 30-40%, NO incluye implementación
- NPS ≥50, completion ≥95%, skills mastery ≥85% son targets de calidad mínima

**Garantías**:
- Cohort size 8-20 (sino reschedule)
- Curriculum customizado 100% (no genérico)
- Job placement support (si B2C) × 90 días post-bootcamp
- Alumni community acceso permanente

**Límites**:
- Bootcamp NO incluye post-bootcamp implementation coaching (separate product)
- Capstone es learning artifact, no empresa/producto final
- Job placement support = networking board + mentoring, no direct hiring
- Idioma: Español (traducción disponible bajo demanda, cost extra)

## Detalles Expandidos por Bootcamp

### BC-01: Office Automation + AI (Microsoft 365 + Copilot)

**Código:** BC-01 | **Duración:** 3 semanas | **Precio:** Corp 18M COP | Indiv 800K COP

**Visión:** "El futuro del trabajo no es reemplazar personas; es amplificarlas. Office 365 + Copilot = cada persona hace el trabajo de 1.5 personas."

**Objetivos de Aprendizaje:**
1. Dominar Microsoft 365 stack (Teams, SharePoint, OneDrive, Forms, etc.)
2. Automatizar workflows comunes con Power Automate (no-code, low-code)
3. Usar Copilot efectivamente para redacción, análisis, síntesis
4. Diseñar e implementar automation suite para departamento específico

**Arquitectura Curricular:**

**WEEK 1: Foundations**
- Day 1: M365 ecosystem overview, governance
- Day 2: Teams + SharePoint (collaboration fundamentals)
- Day 3: Forms + Excel (data collection + analysis)
- Day 4: Power Automate basics (first automation)
- Day 5: Capstone project scoping

**WEEK 2: Copilot + Power Platform**
- Day 1-2: Copilot deep-dive (writing, analysis, prompting)
- Day 3-4: Power Automate advanced (conditional logic, error handling)
- Day 5: Squad integration with existing systems

**WEEK 3: Implementation + Polish**
- Day 1-2: Squad builds automation suite
- Day 3: User testing + iteration
- Day 4: Training materials + handoff plan
- Day 5: Presentations + deployment

**Capstone Project:**
Design + deploy automation suite for [Dept]: 5-10 common workflows automated (prospect list automation, report generation, approval routing, etc.)

**Success Metrics:**
- Automation suite reduces manual work by ≥ 20%
- Team trained + confident using automations
- Documentation complete (for future maintenance)

**Target Audience Deep-dive:**
- **Office managers**: Love this (reduce admin work 50%+)
- **Data analysts**: Excited (automate data pipelines, focus on analysis)
- **Finance/HR**: Mission-critical (workflows = compliance)
- **Sales ops**: High ROI (lead qualification automation, reporting)

Automated sales funnel for specific ICP:
- Prospect list + scoring model (AI-powered lead qualification)

### BC-03: Ways of Working (Agile + GTD + PKM)

**Código:** BC-03 | **Duración:** 3 semanas | **Precio:** Corp 18M COP | Indiv 800K COP

**Visión:** "Combinamos lo mejor de Agile (iteration, flow), GTD (clarity, commitment), PKM (knowledge leverage) en un way-of-working integrado."

**Objetivos de Aprendizaje:**
1. Entender Agile beyond ceremonies (mindset, rituals, culture)
2. Implement GTD en equipo (shared clarity, reduced cognitive load)
3. Design PKM para equipo (reusable knowledge, faster onboarding)
4. Fuse into coherent operating system (no siloed frameworks)

**Arquitectura Curricular:**

**WEEK 1: Agile Fundamentals + GTD Basics**
- Day 1: Agile mindset (principles > ceremonies)
- Day 2: Scrum/Kanban deep-dive (choosing right cadence)
- Day 3: GTD frameworks (capture, clarify, organize)
- Day 4: Mapping current way-of-working (baseline)
- Day 5: First iteration of integrated process

**WEEK 2: PKM + Team Knowledge Systems**
- Day 1: Obsidian/Notion for teams (architecture, governance)
- Day 2-3: Decision documentation, meeting notes, institutional memory
- Day 4: Integration with Agile workflows (backlog > wiki)
- Day 5: Testing with squad

**WEEK 3: Operationalization + Playbook**
- Day 1-2: Squad refines ways-of-working based on testing
- Day 3: Documentation (process docs, templates, decision trees)
- Day 4: Training for broader team (if B2B) or marketing (if B2C)
- Day 5: Presentations + rollout plan

**Capstone Project:**
Ways-of-Working Playbook (30 pages):
- Integrated process map (how we work, cadence, rituals)
- Governance (who decides what, escalation paths)
- Templates (project charter, decision log, retrospective)
- Tool stack (which tool for which purpose)
- First 30-day implementation plan

**Success Metrics:**
- Team reports clarity increase (survey: ≥ 4/5)
- Cycle time reduction ≥ 20% (less context switching)
- Knowledge reuse (new team member onboarding 50% faster)

**Audience Impact:**
- **Managers**: Clear workflows, easier delegation, team development
- **Scrum masters**: Framework-agnostic (not just Scrum police)
- **Teams**: Sense of ownership, autonomy, flow state

### BC-04: Amplified Work (Custom GPTs & Agents)

**Código:** BC-04 | **Duración:** 3 semanas | **Precio:** Corp 18M COP | Indiv 800K COP

**Visión:** "Custom GPTs + Agents = AI that knows YOUR context. No more generic ChatGPT; every workflow gets an AI copilot."

**Objetivos de Aprendizaje:**
1. Understand LLM architecture + capabilities/limitations
2. Design custom GPTs for specific workflows (assistant model)
3. Build agentic systems (reasoning, tool use, iterative problem solving)
4. Operationalize + scale (API, governance, monitoring)

**Arquitectura Curricular:**

**WEEK 1: LLM Fundamentals + Custom GPT Design**
- Day 1-2: How LLMs work (tokens, embeddings, attention)
- Day 3: Prompt engineering advanced (system messages, few-shot, reasoning)
- Day 4: Custom GPT design (for company use case)
- Day 5: First GPT prototype (simple, tested)

**WEEK 2: Agents + Tool Integration**
- Day 1: Agent concepts (react, thought-action-observation)
- Day 2-3: API integration (connect GPT to company systems)
- Day 4: Building simple agent (with error handling)
- Day 5: Testing + iteration with users

**WEEK 3: Scale + Deploy**
- Day 1-2: Squad builds 2-3 agents (different domains)
- Day 3: Governance + safety (who can do what, output review)
- Day 4: Operationalization (versioning, monitoring, updates)
- Day 5: Presentations + deployment strategy

**Capstone Project:**
2-3 Custom GPTs/Agents deployed:
- Sales copilot (prospecting assistant)
- Customer support agent (first-level triage)
- Internal knowledge assistant (Q&A against company docs)

**Success Metrics:**
- Agents solve 80%+ of use cases without human intervention
- Latency <5 seconds (user-acceptable)
- Safety score ≥ 95% (no hallucinations in critical domain)

**Technical Depth:**
- **Engineers**: API design, LLMOps, prompt versioning, testing
- **Product managers**: UX design, user research, success metrics
- **Ops**: Governance, rollout, monitoring, support

### BC-05: Vibe Coding (No-code Apps v0 + Stitch)

**Código:** BC-05 | **Duración:** 3 semanas | **Precio:** Corp 18M COP | Indiv 800K COP

**Visión:** "No-code isn't a limitation; it's liberation. Go from idea to MVP in 3 weeks without writing code."

**Objetivos de Aprendizaje:**
1. Master no-code platforms (Bubble, FlutterFlow, Airtable)
2. Design MVPs that people love (product thinking, not just features)
3. User test ruthlessly (fail fast, iterate quickly)
4. Go live (deployment, monitoring, user feedback loops)

**Arquitectura Curricular:**

**WEEK 1: Product Design + No-code Fundamentals**
- Day 1: Product thinking (problem-solution fit, MVP definition)
- Day 2-3: Platform deep-dive (Bubble or FlutterFlow, data modeling)
- Day 4: Build first feature (login, database, display)
- Day 5: MVP definition for capstone (problem statement + scope)

**WEEK 2: Building + User Testing**
- Day 1-2: Squad builds core features
- Day 3: Invite first users (ideally 3-5 actual customers)
- Day 4: Collect feedback, prioritize improvements
- Day 5: First iteration complete

**WEEK 3: Polish + Launch**
- Day 1-2: Final features, UX refinement
- Day 3: Deployment (custom domain, database backups)
- Day 4: Collect more user feedback, refine
- Day 5: Present + discuss next steps (funding, growth)

**Capstone Project:**
Functional MVP (v0):
- Solves real problem (customer has $, will pay if it works)
- 3-5 core features (not 50)
- User-tested (3+ users, ≥ 5 feedback sessions)
- Live + accessible (anyone can try)
- Next steps documented (roadmap, go-to-market)

**Success Metrics:**
- MVP deployed + live (not demo, not prototype)
- User feedback ≥ 4/5 on usefulness
- Time-to-MVP ≤ 3 weeks (proof of no-code speed)
- Customer acquisition strategy defined (even if 0 customers yet)

**Startup Mindset:**
- **Founders**: Validate idea fast, avoid wasting months coding
- **Intrapreneurs**: Launch proof-of-concept in 3 weeks (not 3 months)
- **Product managers**: Experience speed of iteration (game changer)

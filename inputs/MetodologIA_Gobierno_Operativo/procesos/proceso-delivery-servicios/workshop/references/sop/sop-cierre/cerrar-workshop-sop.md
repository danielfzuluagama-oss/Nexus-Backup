# SOP: Cerrar Workshop

**Versión:** 2.0 | **Vigencia:** 2026-01 | **Dueño:** Coordinador de Operaciones | **Última Actualización:** 2026-03-24

---

## Identificación

- **Código SOP**: SOP-CIERRE-WS
- **Proceso Padre**: Entregar Workshop (Ver: entregar-workshop-proceso.md)
- **Fase**: Cierre & Nurturing (T+1 a T+30, 30 días)
- **Responsable Principal**: Coordinador de Operaciones (Delivery)
- **Responsable Secundario**: Especialista Nurturing (email sequences)
- **Stakeholders**: Account Manager (conversion), Facilitador (learnings), CRM Admin (tagging)
- **Input desde**: SOP-FAC-WS (video, fotos, NPS raw, action cards)
- **Output hacia**: Nurturing Process (leads para segundo paso), Commercial (conversion tracker)

---

## Objetivo

Maximizar impacto post-workshop mediante recopilación de data (NPS), entrega de materiales, nurturing 30d, y segmentación precisa de leads para siguiente etapa.

---

## Supuestos & Criterios de Éxito

**Supuestos**:
1. Facilitador/Asistente entregaron raw data T+0 (video, fotos, NPS cards, action cards scans)
2. Email list validada (correos activos, sin bounces)
3. CRM accesible y con estructura de tagging pre-diseñada
4. Templates de emails pre-escritos por Contenido (no creados ad-hoc)

**Criterios Binarios**:
- [ ] NPS calculado T+1
- [ ] Video procesado T+3
- [ ] Certificados entregados T+3
- [ ] Email 1 enviado T+4
- [ ] Leads segmentados T+7
- [ ] Action-item survey enviado T+22

**Limite**: Si alguno falla T+deadline, escalar a Ops Manager (máx 24h retraso permitido antes de escalate CEO)

## T+1 (24 horas post-workshop)

### Actividad 1: Consolidate Documentation

**Responsable**: Coordinador Ops + Facilitador

**Duración**: 2 horas

**Pasos**:
1. **Video processing**:
   - Move raw video file from recording device to secure folder
   - Generate SRT file (subtitle/transcription)
   - Create 3 clips (intro, key moment, action planning)
   - Upload to shared Google Drive

2. **Photo curation**:
   - Download all photos from Asistente
   - Select 8-12 best shots (group, canvases, energy)
   - Organize in Drive folder: `/ejecucion/fotos/`
   - Create simple album summary

3. **Attendance verification**:
   - Cross-reference sign-in sheet with roster
   - Calculate attendance rate (# present / # expected)
   - Flag any issues (very low attendance, notable absences)

4. **NPS data collation**:
   - Collect NPS cards from Asistente
   - Enter into spreadsheet:
     - | Name | NPS Score | Comments |
     - Calculate average NPS
     - Identify top promoters (9-10) + detractors (<7)

**Output**: All raw data consolidated in shared folder

---

### Actividad 2: Send Welcome Email + Materials

**Responsable**: Coordinador Ops

**Duración**: 1 hour

**Pasos**:
1. **Prepare email**:
   ```
   Asunto: [WS-XX] - Muchas Gracias + Tus Materiales Dentro

   Dear [Participant],

   Thank you so much for joining us yesterday at [Workshop Title].
   Your energy, questions, and commitment made it special.

   What happens next:
   - Tomorrow (T+2): Video + slides will be available to download
   - Friday (T+3): Certificate of completion (shareable on LinkedIn)
   - Weekly (next 3 weeks): Insights + resources to deepen learning

   The action plan you created yesterday? That's your roadmap.
   Start with one thing this week.

   Questions? Reply to this email.

   Warmly,
   [Facilitador Name]
   ```

2. **Segment by attendance**:
   - All attendees get thank you email
   - Non-attendees get "sorry missed you" email with recording link

3. **Send within 24h of workshop end**

**Output**: Emails sent (tracked in Mailchimp/CRM)

---

### Actividad 3: NPS Analysis

**Responsable**: Coordinador Ops + Especialista Contenido

**Duración**: 1.5 hours

**Pasos**:
1. **Score breakdown**:
   - Promoters (9-10): Calculate count + %
   - Passives (7-8): Calculate count + %
   - Detractors (0-6): Calculate count + %
   - **NPS Formula**: (# Promoters - # Detractors) / # Total × 100

2. **Qualitative analysis**:
   - Read all open-ended feedback
   - Identify themes:
     - What was most valuable?
     - What could be improved?
     - Any workshop-specific insights?
   - Create short summary (5-7 bullet points)

3. **Data quality check**:
   - If NPS < 30: investigate why (content, facilitation, logistics)
   - If NPS 30-45: good but room to grow
   - If NPS ≥ 45: celebrate, share best practices

4. **Document findings**:
   - Create post-workshop report (1 page):
     - NPS score + breakdown
     - Attendance + engagement data
     - Top feedback points
     - Recommendations for next iteration

**Output**: NPS report in shared Drive folder

## T+2 to T+3 (Days 2-3)

### Actividad 4: Process Video & Create Deliverables

**Responsable**: Content Specialist (or external video editor)

**Duración**: 4-6 hours

**Pasos**:
1. **Video editing**:
   - Trim raw footage (remove pre/post-session chatter)
   - Add title slide + closing slide with branding
   - Embed recording + transcription
   - Create chapters (by segment)
   - Export in 2 formats:
     - High quality (1080p) for download
     - Compressed (720p) for streaming

2. **Create transcription**:
   - Use auto-transcribe (Google Meet, Otter.ai) or manual
   - Edit for accuracy
   - Create searchable PDF + text file

3. **Generate certificate**:
   - Use template (Canva or design tool)
   - Personalize with:
     - Participant name
     - Workshop title + date
     - Facilitador signature
     - MetodologIA seal
   - Export as PDF + PNG
   - Prepare for delivery (email link to self-serve download)

4. **Create 1-page takeaway**:
   - Summary of key concepts
   - Canvas templates
   - Resource links
   - Action planning template (for reference)
   - PDF + Google Doc version

**Output**: Video, transcript, certificate, 1-pager ready for distribution

---

### Actividad 5: Distribute T+3

**Responsable**: Coordinador Ops

**Duración**: 1 hour

**Pasos**:
1. **Send email #1: Video + Materials**:
   ```
   Asunto: [WS-XX] - Tu Video + Materiales para Descargar

   Hi [Name],

   Here are your workshop materials:
   - Video (watch on Google Drive or download)
   - Transcript (searchable PDF)
   - 1-page takeaway + canvas templates
   - Certificate of completion (print or share on LinkedIn)

   Access: [shared link] (expires in 30 days)

   Questions? Let me know.
   ```

2. **Create shared access**:
   - Google Drive link (read-only)
   - Expiration date (30 days)
   - Alternative: Dropbox link if Drive unavailable

3. **Prepare certificate emails**:
   - Personalized link to download certificate
   - LinkedIn sharing prompt
   - "Share your achievement!"

4. **CRM logging**:
   - Log T+3 completion
   - Mark as "materials delivered"
   - Note NPS score

**Output**: Emails sent, access granted, CRM updated

## T+4 to T+7 (Email Nurturing - Email #1)

### Actividad 6: Segment & Personalize

**Responsable**: Especialista Nurturing

**Duración**: 2 hours

**Pasos**:
1. **Segment participants**:
   - By NPS: Promoters (9-10) | Passives (7-8) | Detractors (<7)
   - By role: C-Suite | Manager | IC
   - By engagement: High (spoke 3+ times) | Medium (1-2 times) | Low (silent)
   - By likelihood to bootcamp: High | Medium | Low (based on role + NPS)

2. **Create segment list**:
   - Promoters: "Champion" segment (nurture for testimonial + bootcamp)
   - Passives: "Warm" segment (content + engagement)
   - Detractors: "Recovery" segment (understand issue, offer support)

3. **Prepare Email #1** (T+4 to T+7):
   - **Subject**: [Workshop Title] - 1 Key Insight You Might Have Missed
   - **Content**:
     - Recap 1 major concept (500 words)
     - Share 1 deep-dive resource (article, video, tool)
     - Ask: "What action from your list did you tackle this week?"
     - CTA: "Reply with your update"
   - **Personalization by segment**:
     - Promoters: "I'd love to hear how you're using this..."
     - Passives: "If something was confusing, let's clarify..."
     - Detractors: "I want to make sure you got value. How can we help?"

**Output**: Segmented list + personalized email draft

---

### Actividad 7: Send Email #1

**Responsable**: Coordinador Ops

**Pasos**:
1. Send to all participants (T+4 to T+7)
2. Track opens + clicks in email tool (Mailchimp)
3. Log in CRM (activity record)

**Output**: Email metrics (open rate, click rate)

## T+8 to T+14 (Email Nurturing - Email #2)

### Actividad 8: Create Case Study + Social Proof

**Responsable**: Especialista Nurturing

**Duración**: 2 hours

**Pasos**:
1. **Research case study**:
   - Find MetodologIA case study relevant to workshop topic
   - Story of company that used this framework → results
   - Structure: Situation | Action | Results

2. **Prepare Email #2** (T+8 to T+14):
   - **Subject**: How [Company] Used [Framework] to Achieve [Outcome]
   - **Content**:
     - 1 relevant case study (600 words)
     - Quote from client: why this mattered
     - Comparison: "You did the same work in our workshop yesterday"
     - CTA: "If you want to go deeper, we have something special launching..."

3. **Identify promoters for outreach**:
   - Reach out to NPS 9-10 individuals via LinkedIn
   - Ask: "Would you be willing to share how you're using this?"
   - Offer: "Short 15-min call to capture your story"
   - Seed testimonials for future marketing

**Output**: Email #2 + LinkedIn outreach to promoters

---

### Actividad 9: Account Manager 1:1 Outreach (B2B)

**Responsable**: Account Manager

**Duración**: 3-4 hours (across T+8 to T+14)

**Pasos**:
1. **Identify corporate participants**:
   - Decision-makers, team leads, influencers
   - Filter: NPS ≥ 7 + role of influence

2. **1:1 call schedule**:
   - Email: "Quick 15-min call to hear how it's landing with your team?"
   - Goal: Understand adoption, surface next opportunities
   - Take notes: Actions taken, team response, expansion potential

3. **Identify bootcamp-qualified**:
   - NPS 8+ + clear need for deeper learning
   - Role: Manager or above (decision-maker)
   - Tag in CRM: "Bootcamp-qualified"

4. **Email follow-up**:
   - "Based on our chat, here's what I'm thinking..."
   - Mention bootcamp as next step (if fits)
   - Offer: "Let's do a quick exploratory call with your team"

**Output**: Call notes + CRM tags + bootcamp prospects identified

---

## T+15 to T+21 (Email Nurturing - Email #3)

### Actividad 10: Prepare Email #3 + Bootcamp Invitation

**Responsable**: Especialista Nurturing + Account Manager

**Duración**: 2 hours

**Pasos**:
1. **Prepare Email #3** (T+15 to T+21):
   - **Subject**: The Next Step (for people ready to go deeper)
   - **Content**:
     - Recap what they learned in workshop
     - Introduce bootcamp as natural next step (3-week intensive)
     - Benefits: deeper skills, cohort learning, project-based
     - Early bird pricing (if applicable)
     - CTA: "Apply here" or "Book a quick call"

2. **Segment send**:
   - Promoters (NPS 9-10): Get bootcamp email + 1:1 call offer
   - Passives (NPS 7-8): Get bootcamp email + group info session
   - Detractors (NPS <7): Skip bootcamp email; send "support" email instead

3. **Account Manager outreach**:
   - Corporate participants already contacted 1:1
   - Individual participants: Offer group webinar (Bootcamp overview)

**Output**: Email #3 sent, bootcamp prospects identified, conversions tracked

## T+22 to T+30 (Final Follow-up & Data Consolidation)

### Actividad 11: 30-day Action Impact Survey

**Responsable**: Especialista Nurturing

**Duración**: 1 hour (setup); 1 week (collection)

**Pasos**:
1. **Create survey** (T+22):
   - "30 Days Later" survey (3-5 questions):
     - Did you implement any of your 3 action items?
     - What were the results?
     - How has this changed your thinking?
     - Would you recommend this workshop? (NPS again)
     - Interest in bootcamp / next workshop?
   - Use Typeform or Google Form (embedded in email)

2. **Send survey** (T+22):
   - Subject: "Quick Check-in: How's It Going with Your Action Plan?"
   - Remind them of their 3 commitments
   - Make it easy (2-min survey)

3. **Collect responses** (T+23 to T+29):
   - Track response rate (target ≥ 40%)
   - Note patterns: who completed actions, who didn't
   - Analyze impact quotes ("I've already...", "This helped me...")

**Output**: 30-day action impact data

---

### Actividad 12: Consolidated Post-Workshop Report

**Responsable**: Coordinador Ops

**Duración**: 2 hours (T+28)

**Pasos**:
1. **Compile all data**:
   - Attendance: # present, # registered, % rate
   - NPS: score, breakdown, top feedback
   - Engagement: # participated, quality of canvases
   - Email metrics: open rates, click rates, responses
   - Action completion: % who took action, types of actions
   - Bootcamp conversion: # interested, # with calls scheduled

2. **Create summary report** (1-2 pages):
   - Title: [Client] | [WS-XX] | [Date] - Post-Workshop Report
   - Sections:
     - Executive summary (NPS, attendance, key insight)
     - Detailed metrics (tables)
     - Participant feedback (top 3 positives + 2 improvements)
     - Lead status (bootcamp-qualified list)
     - Recommendations for future
     - Lessons learned (content, facilitation, logistics)

3. **Share with stakeholders**:
   - Internal: CEO Delivery, Account Manager, Contenido
   - Client: Account Manager shares with primary contact
   - Facilitador: For continuous improvement

**Output**: Post-workshop report (PDF + shared doc)

---

### Actividad 13: Lead Handoff to Nurturing/Commercial

**Responsable**: Especialista Nurturing + Account Manager

**Duración**: 1 hour (T+29)

**Pasos**:
1. **Create lead inventory**:
   - Export from CRM all tagged leads
   - Segment:
     - **Bootcamp-ready**: NPS 8+ + decision-maker → Account Mgr (sales conversation)
     - **Warm leads**: NPS 7 + influencer → Nurturing (content track)
     - **Recovery**: NPS <7 → Ops (re-engagement attempt)

2. **Account Manager handoff**:
   - List of bootcamp-ready prospects
   - Suggested approach: 15-min exploratory call
   - Talking points: workshop insights + next level bootcamp

3. **Nurturing handoff**:
   - Warm lead list
   - 3-month nurturing sequence:
     - Weekly: Industry content, tool tips, success stories
     - Monthly: Webinar invitations, new workshop launches
     - Quarterly: Bootcamp open house (if interested)

4. **Recovery outreach**:
   - Small group (detractors)
   - Personal email: "We want to make sure this landed for you. Can we do better?"
   - Offer: 1:1 coaching call, group session, money back (if applicable)

**Output**: Lead segments in CRM + handoff notes to each team

## Casos Borde (Cierre Phase)

**Caso 1: NPS <30 (indica posible issue sistémica)**
Trigger: Post-workshop NPS <30, >40% detractores
Decision: Root cause analysis inmediata (T+2):
- ¿Fue facilitación? Facilitador auto-evalúa.
- ¿Fue contenido? Especialista Contenido audita.
- ¿Fue logística? Coordinador Ops revisa.
Action: Si es facilitador issue → paired coaching con facilitador senior antes del próximo workshop.
Escalate to CEO Delivery si incertidumbre.

**Caso 2: <30% response rate en NPS survey (data insuficiente)**
Trigger: Enviamos NPS, solo 5 de 20 responden
Decision: Segunda oleada T+7 (reminder email). Si aún <40%: proceder con data parcial (anotar como "low response sample bias").
Rationale: NPS parcial > NPS none. Buscamos tendencia, no exactitud.

**Caso 3: Video no grab corruptamente (file corrupted)**
Trigger: Tech issue, video grabado pero inplayable
Decision: Crear transcripción manual (facilitador + asistente, 4h trabajo) + screenshot gallery. Entregar como "transcript + slides visual".
Rationale: Transcripción preserva contenido. Video deseable, no crítico.

**Caso 4: Participante solicita certificado con nombre incorrecto T+10**
Trigger: "Mi nombre es Juan Pablo, certificado dice Juan"
Decision: Regenerar certificado (15 min). Re-enviar T+0 (misma día). Disculpa breve en email.
Escalate: Si >2 errores en cohort → revisar proceso de data entry.

**Caso 5: Account Manager no disponible para outreach T+8**
Trigger: AM enfermo, fuera de oficina, etc.
Decision: Ops Coordinator puede hacer outreach T+8-14 (usar template standardizado). No esperar AM.
Rationale: Momentum decay es real. Mejor outreach mediocre que ninguno.

**Caso 6: Lead "bootcamp-qualified" no responde a outreach T+30**
Trigger: NPS 9, C-level, pero 3 intentos de contact = no responde
Decision: Documentar como "attempted, not interested", no spam further. Marcar para revisit en Q3.
Escalate: Solo si es cliente corporativo strategic (no individual).

---

## Anti-Patterns (QUÉ NO HACER)

- NO esperar respuesta 100% NPS (pasa T+7 si <70% response)
- NO retardar envío de materiales esperando video perfecto (entrega imperfecta > entrega tardía)
- NO personalizar email Número 1 sin template (consistency matters más que personalization en T+1)
- NO olvidar tagging en CRM (data loss = no segmentation = no targeting)
- NO enviar email nurturing a detractores sin recovery attempt primero

---

## Fallbacks Operativos

| Falla | Fallback | Tiempo Max |
|-------|----------|-----------|
| Video no cargue por size | Comprimir a 480p o enviar link Drive (no adjunto) | T+3 |
| Certificados generados con typos | Regenerar + re-enviar, no es criticidad alta | T+4 |
| Email template no disponible | Escribir rápido (15 min), usar formato simple | T+4 |
| >30% NPS detractores | Análisis de root cause, documentar, no actitud defensiva | T+2 |
| Email open rate <20% (T+7) | Resend con subject line diferente T+10 | T+10 |

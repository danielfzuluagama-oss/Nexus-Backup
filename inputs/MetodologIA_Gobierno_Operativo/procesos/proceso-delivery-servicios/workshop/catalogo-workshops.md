## Supuestos & Límites

**Supuestos**:
- Cada workshop asume participantes con mínimo interés en IA/digital (no es educación remedial)
- Precio corporativo incluye facilitador travel si dentro de región; fuera de región → costo adicional
- Prerequisitos son recomendados, no bloqueantes (facilitador adapta si skill gap existe)
- Catalogo vigente sin cambios hasta 2026-12-31; actualizaciones requieren aprobación VP Contenido

**Límites**:
- Workshops NO incluyen implementación post-3h (solo transfer de frameworks)
- Customización >50% requiere cambio de modalidad a consultoría (fuera de este catálogo)
- Grupos >30 personas requieren 2 facilitadores (costo adicional)
- Idiomas: Español solo (traducción disponible bajo demanda, costo extra)

## Detalles Expandidos por Workshop

### WS-01: Introducción al Ecosistema de IA

**Código:** WS-01 | **Duración:** 3 horas | **Precio:** Corp 3M COP | Indiv 200K COP

**Visión:** "Antes de transformar, necesitas ver el tablero. Mapeamos el landscape de IA, identificamos donde tu organización puede jugar, y construimos el argumento para la acción."

**Objetivos de Aprendizaje:**
1. Entender el landscape actual de AI (LLMs, agents, multimodal, reasoning)
2. Identificar 3-5 oportunidades de aplicación en contexto específico
3. Evaluar madurez organizacional para adopción AI
4. Construir narrative convincente para buy-in ejecutivo

**Segmentación por Audiencia:**
- **CTO/Technology Leaders**: Focus en arquitectura, integration points, technical risks
- **C-Suite/Business**: Focus en ROI, competitive advantage, time-to-value
- **Innovation Teams**: Focus en ideation, prototyping, fail-fast methodology

**Metodología:**
1. Ecosystem briefing (20 min): State of AI, key technologies, use cases
2. Context mapping (40 min): Current state, pain points, opportunities
3. Opportunity scoping (45 min): 3-5 opportunities + feasibility assessment
4. Action planning (15 min): Next steps, resource needs, timeline

**Herramientas Clave:**
- **Ecosystem Map Canvas**: 4-quadrant framework (technology maturity vs. business impact)
- **Opportunity Scorecard**: Ease/Impact scoring
- **100-Day Plan Template**: Quarterly roadmap

**Métricas de Éxito:**
- NPS ≥ 50
- 80% participantes pueden articular 3 aplicaciones específicas
- 100% completaron action plan

**Contexto de Facilitación:**
- Tono: "Realista pero hopeful" (no promesas vacías, sí oportunidades concretas)
- Energía: Educativa + empowering (no academic)
- Timing: Break en minuto 90 con energizer

### WS-02: Advanced Prompting: Domina la Librería de Prompts

**Código:** WS-02 | **Duración:** 3 horas | **Precio:** Corp 3M COP | Indiv 200K COP

**Visión:** "Los LLMs son herramientas indiferentes; los prompts son lo que las hace inteligentes. Construimos tu librería de producción."

**Objetivos de Aprendizaje:**
1. Dominar 5+ técnicas avanzadas (chain-of-thought, role-playing, few-shot, constitutional)
2. Construir 15+ prompts validados para flujos específicos
3. Entender limitations de LLMs y cómo diseñar para ellos
4. Setup reproducible prompt testing framework

**Segmentación:**
- **Engineers**: Focus en prompt validation, testing, CI/CD
- **Content/Marketing**: Focus en creative applications, A/B testing
- **Product/Data**: Focus en performance metrics, iteration

**Metodología:**
1. Foundations (30 min): Attention mechanisms, token economy, temperature/sampling
2. Techniques deep-dive (75 min): Chain-of-thought, role-playing, few-shot, constitution
3. Library building (45 min): Co-create 15+ prompts + test harness
4. Deployment (10 min): Integration, versioning, monitoring

**Herramientas:**
- **Prompt Template Library**: 50+ starter templates (Google Docs)
- **Testing Framework**: Scorecard para evaluación de output quality
- **Integration Guide**: APIs (OpenAI, Anthropic, open-source)

**Métricas de Éxito:**
- NPS ≥ 50
- 100% tienen librería de prompts versioned
- 90%+ implementan en producción dentro de 30 días

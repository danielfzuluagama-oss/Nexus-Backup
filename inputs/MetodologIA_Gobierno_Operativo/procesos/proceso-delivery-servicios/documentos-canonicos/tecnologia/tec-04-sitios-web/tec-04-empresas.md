# TECNOLOGÍA T4 — Sitios Web
## Documento Canónico | Segmento: EMPRESAS

**Código:** TEC-04-EMPRESAS | **Versión:** 1.0 | **Fecha:** 2026-03-24
**Segmento:** Empresas (B2B — Corporativo)
**Precio canónico:** COP 500K - COP 12M (según alcance) | **Duración:** 1-6 semanas

---

## 1. Ficha Rápida
Desarrollo de sitios web profesionales para presencia digital corporativa. Rango: landing pages simples (1 semana, COP 500K) hasta sitios corporativos complejos (6 semanas, COP 12M). Incluye diseño, desarrollo, SEO básico, hosting, CMS.

**Objetivo:** Establecer presencia digital profesional, generar leads, comunicar propuesta de valor.

---

## 2. Definición y Alcance
Desarrollo e implementación de sitios web modernos con diseño profesional, contenido optimizado y funcionalidad requerida. Desde landing pages de una sección hasta sitios corporativos multi-página con CMS.

**Tipos de sitios:**
- **Landing page:** 1-3 secciones, conversión a leads (COP 500K-1.5M, 1 semana)
- **Sitio informativo:** 5-10 páginas, contenido sin transacciones (COP 2-4M, 2-3 semanas)
- **Sitio corporativo:** Branding completo, 15+ páginas, CMS, blog (COP 5-8M, 4 semanas)
- **E-commerce ligero:** Productos, carrito, pagos integrados (COP 8-12M, 5-6 semanas)

---

## 3. Audiencia Corporativa
- **Decisor:** Director General, Director de Marketing, Emprendedor
- **Usuario final:** Visitantes externos (clientes potenciales, clientes actuales)
- **Gestor interno:** Comunicación, marketing, administrador de contenidos
- **Rango:** PYMES a grandes empresas, cualquier sector

---

## 4. Propuesta de Valor
- **Profesionalismo:** Presencia digital que comunica seriedad y calidad
- **Velocidad:** Sitio en 1-6 semanas, no meses de desarrollo tradicional
- **Costo-efectivo:** COP 500K-12M vs. COP 20M+ en desarrollos complejos
- **SEO incluido:** Optimizado para búsqueda desde el inicio
- **Responsive:** Funciona perfecto en desktop, tablet, móvil
- **Moderno:** Tech stack actual, performance optimizado
- **Control:** Full propiedad, CMS intuitivo para actualizar contenido
- **Escalabilidad:** Puede crecer con la empresa

---

## 5. Estructura y Fases

### Fase 1: Estrategia y Diseño (Semana 1)
- Workshop de definición (2-3h)
  - Objetivos del sitio
  - Audiencia target
  - Mensajes clave
  - Conversiones deseadas
- Análisis de competencia
- Propuesta de estructura y navegación
- Diseño visual (mockups/wireframes)
- Aprobación de diseño

### Fase 2: Desarrollo Frontend (Semana 2-3)
- Implementación de diseño
- HTML/CSS/JavaScript optimizado
- Responsive design (mobile-first)
- Integración de CMS (si aplica)
- Formularios y captura de leads

### Fase 3: Desarrollo Backend (Semana 2-4)
- Backend de CMS o API (si aplica)
- Base de datos
- Sistema de seguridad y autenticación
- Email/notificaciones
- Integración de pagos (si aplica)

### Fase 4: Contenido y Optimización (Semana 3-4)
- Incorporación de contenido (textos, imágenes, videos)
- SEO on-page (keywords, meta tags, estructura)
- Optimización de performance
- Testing en múltiples dispositivos y navegadores

### Fase 5: Deployment y Launch (Semana 4-6)
- Deployment en servidor de producción
- Configuración de dominio y SSL
- Setup de analytics (Google Analytics, etc.)
- Testing final
- Capacitación en CMS
- Launch

---

## 6. Entregables

**Todos los sitios incluyen:**
1. Sitio web completamente funcional deployado en producción
2. Diseño profesional responsivo
3. Código fuente en repositorio Git (propiedad cliente)
4. Sistema de CMS para actualizar contenido
5. Setup de Google Analytics y Search Console
6. Documentación técnica y de usuario
7. Capacitación en CMS (1-2 horas)
8. Hosting incluido (primeros 3 meses)
9. Soporte técnico 4 semanas

**Componentes típicos:**
- Diseño profesional (Figma → HTML)
- Responsive design (desktop/tablet/móvil)
- Formularios de contacto con validación
- Blog/news (si aplica)
- CMS intuitivo (WordPress, Strapi, custom)
- SEO on-page (keywords, meta, sitemap, robots.txt)
- Performance optimization (lazy loading, caché, CDN)
- SSL/HTTPS
- Email notifications
- Google Analytics

**Opcionales (según plan):**
- Integración de pagos (Stripe, MercadoPago)
- Chatbot
- Booking system
- Multi-idioma
- Integración con CRM
- Integraciones adicionales

## Consideraciones SEO
- **Keyword research:** Identificadas en fase inicial
- **On-page SEO:** Títulos, descripciones, headers, content optimization
- **Technical SEO:** Sitemap, robots.txt, schema markup, Core Web Vitals
- **Mobile:** Mobile-first indexing considerado
- **Performance:** Optimización de carga y CWV
- **Seguimiento:** Google Analytics 4 + Search Console setup

**Nota:** No incluye estrategia de SEO continua o link building (esos son servicios separados)

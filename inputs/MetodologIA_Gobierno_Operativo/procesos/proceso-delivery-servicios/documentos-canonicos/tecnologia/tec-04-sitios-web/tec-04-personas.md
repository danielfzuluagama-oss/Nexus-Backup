## 1. Ficha Rápida
**Servicio de desarrollo de sitios web** para profesionales independientes, creadores, freelancers.

| Aspecto | Detalle |
|--------|---------|
| **Público** | Profesionales, creadores, consultor independiente |
| **Alcance** | 1 sitio web profesional |
| **Inversión** | COP 500K-12M (proyecto) |
| **Tiempo** | 3-12 semanas |
| **Tipo** | Portfolio, landing, tienda simple, blog |
| **Tecnología** | Next.js, headless CMS, responsive |
| **Soporte** | 6 meses incluido |

---

## 2. Modelo de Servicio
- **Desarrollo de sitio web:** One-time project.
- **Propiedad:** Cliente es propietario 100%.
- **Escalabilidad:** Diseñado para escalar a pequeña/mediana escala.
- **Modelo:** Pago fijo por proyecto.

---

## 3. Tipos de Sitios
**Por inversión y complejidad:**

| Tipo | Descripción | Inversión | Semanas |
|------|-------------|-----------|---------|
| **Landing page** | Presentación + CTA | COP 500K-1.5M | 2-3 |
| **Portfolio/CV** | Proyectos, skills, contacto | COP 800K-2.5M | 3-4 |
| **Blog profesional** | Artículos + email newsletter | COP 1.5M-4M | 4-6 |
| **Tienda simple** | Catálogo 10-50 productos | COP 2M-6M | 5-8 |
| **SaaS MVP** | Aplicación web + landing | COP 3M-12M | 8-12 |

---

## 4. Alcance del Proyecto
**Fase 1: Strategy (5-7 días)**
- Definición de objetivo (brand, lead gen, ventas).
- Wireframes y estructura.
- Content outline.

**Fase 2: Desarrollo (3-10 semanas)**
- Diseño responsivo (mobile-first).
- Frontend (Next.js + Tailwind).
- Backend si es necesario.
- CMS integration (Contentful, Strapi, o simple).
- SEO setup.

**Fase 3: Launch (5 días)**
- Testing cross-browser.
- Performance optimization.
- Domain + SSL.
- Analytics (Google Analytics 4).
- Backup y security.

---

## 5. Tecnología
**Frontend:**
- Next.js (React framework).
- Tailwind CSS (styling).
- Responsive design (mobile, tablet, desktop).

**Backend (si aplica):**
- Node.js + serverless (AWS Lambda, Vercel Functions).
- PostgreSQL o Firebase (BD si necesario).

**CMS:**
- Contentful (headless CMS).
- Strapi (self-hosted).
- Markdown (para blogs simple).

**Hosting:**
- Vercel (recomendado, integración perfecta con Next.js).
- AWS o Netlify si cliente prefiere.

---

## 8. Proceso
1. **Consulta inicial:** Idea, objetivo, público (30 min gratis).
2. **Strategy session:** Wireframes, features, presupuesto.
3. **Firma:** SOW detallado.
4. **Desarrollo:** Sprints 1-2 semanas con updates.
5. **Testing + refinamiento:** Beta testing con cliente.
6. **Launch:** Sitio en vivo + training básico.

---

## 9. Entregas
**Código y accesos:**
- Código fuente (GitHub private repo).
- Acceso a CMS (si aplica).
- Hosting account y dominio a nombre de cliente.
- Documentación técnica.

**Training:**
- 1 hora de training para manage contenido.
- Guía de cómo actualizar sitio.

**Soporte:**
- 6 meses de soporte técnico incluido.
- Post-6 meses, contratos de mantenimiento (COP 300K/mes).

---

## 10. Términos y Condiciones
- **Propiedad:** Cliente es propietario 100% (código + dominio + contenido).
- **Licencia:** Cliente puede usar, modificar, vender libremente.
- **Soporte:** 6 meses incluido de bugs/issues.
- **Mantenimiento post-6m:** Contrato opcional (COP 300K/mes).
- **Datos:** Cliente mantiene confidencialidad del contenido.

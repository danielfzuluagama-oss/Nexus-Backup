# TEC-02 — Agentes IA Autónomos
## Documento Canónico | Segmento: MARCA BLANCA

**Código:** TEC-02-MARCA-BLANCA | **Versión:** 1.0 | **Fecha:** 2026-03-24
**Segmento:** Marca Blanca (White Label License)

---

## 1. Ficha Rápida
**Servicio de desarrollo** de agentes IA autónomos para automatización de workflows. Cliente los entrega bajo su marca.

| Aspecto | Detalle |
|--------|---------|
| **Alcance** | 1-3 agentes IA por contrato anual |
| **Inversión anual** | COP 30M (licencia base) + COP 25M-80M/agente |
| **Modelo de ingresos** | Licencia anual + 5% de ahorros/ingresos generados |
| **Tiempo de desarrollo** | 6-16 semanas por agente (según nivel) |
| **Niveles** | Simple, Compuesto, Orquestador |
| **Tecnología** | LLM agents, RPA, API integration, orchestration |
| **Soporte** | Mantenimiento, optimización, escalabilidad |

---

## 2. Modelo de Licenciamiento
- **Licencia white-label:** 2 años mínimo.
- **Contenido:** Metodología de agentes, arquitectura reference, integration libraries, training.
- **Marca:** 100% del cliente en el agente. MetodologIA como technology partner.
- **Territorio:** Opcional exclusividad (50% premium).
- **Aplicable a:** Consultoras tech, integradores, BPOs, empresas con talento tech.

---

## 3. Contenido Licenciado
**Metodología de desarrollo de agentes:**
- Assessment de procesos (as-is, to-be mapping).
- Selección de nivel de agente (Simple, Compuesto, Orquestador).
- Arquitectura: LLM selection, integraciones, orchestration.
- Desarrollo: Prompting, tool integration, logic implementation.
- Testing: Unit, integration, process acceptance.
- Despliegue: Hosting, monitoring, alerting.
- Monitoreo: Métricas de accuracy, velocity, exception rate.

**Incluido:**
- Process assessment playbook (templates).
- Arquitectura reference (por nivel de agente).
- Decision support tool (qué nivel de agente usar).
- Integration library (APIs, webhooks, RPA connectors).
- Prompting playbook (patrones por caso de uso).
- Testing framework (unit tests, process tests).
- Deployment guide (AWS, Azure, Google Cloud).
- Monitoring dashboard template.
- Documentation template.

---

## 4. Personalización Permitida (hasta 50%)
El cliente PUEDE:
- Seleccionar nivel de agente (Simple, Compuesto, Orquestador).
- Elegir herramientas de integración específicas (APIs, RPA, webhooks).
- Customizar prompting y lógica de negocio completamente.
- Entrenar agente con datos propios (con privacidad asegurada).
- Implementar orquestación multi-agente propia.
- Desplegar en su infraestructura o cloud de preferencia.

El cliente NO PUEDE:
- Vender arquitectura de MetodologIA como propia.
- Usar templates sin atribución a MetodologIA.
- Certificar usuarios sin validación MetodologIA.
- Remover referencias de calidad de MetodologIA.

---

## 5. Certificación de Desarrolladores
**Requisitos:**
1. Experiencia en automatización/RPA (2+ años) O software architecture (3+ años).
2. Capacitación MetodologIA: 4 jornadas (agentes architecture, integration patterns, testing).
3. Evaluación: Desarrollar agente Compuesto observado (2-3 semanas).
4. Recertificación anual (8 horas, COP 3M).

## 7. Control de Calidad
- **Architecture review:** MetodologIA revisa diseño de cada agente antes de go-live.
- **Métricas:** Accuracy 90%+, exception rate <5%, uptime 99%+.
- **Auditoría anual:** Performance de agentes en producción.
- **Evaluación:** Anual de desarrollador (skills, adherencia a estándares).

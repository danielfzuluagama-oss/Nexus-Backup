# TEC-03 — Mini Apps Inteligentes
## Documento Canónico | Segmento: MARCA BLANCA

**Código:** TEC-03-MARCA-BLANCA | **Versión:** 1.0 | **Fecha:** 2026-03-24
**Segmento:** Marca Blanca (White Label License)

---

## 1. Ficha Rápida
**Servicio de desarrollo** de mini apps (4-8 semanas) potenciadas con IA. Cliente las entrega bajo su marca.

| Aspecto | Detalle |
|--------|---------|
| **Alcance** | 1-3 apps por contrato anual |
| **Inversión anual** | COP 25M (licencia) + COP 30M-80M/app |
| **Modelo de ingresos** | Licencia + 5% de ingresos/app |
| **Tiempo desarrollo** | 4-12 semanas por app |
| **Tech stack** | React, Next.js, Flutter, custom integrations |
| **Casos de uso** | Cálculadoras, formatters, integradores, análisis |
| **Escalabilidad** | Serverless, APIs, webhooks |

---

## 2. Modelo de Licenciamiento
- **Licencia white-label:** 2 años mínimo.
- **Contenido:** Metodología de desarrollo, boilerplates, componentes, integrations.
- **Marca:** 100% cliente. MetodologIA como tech partner.
- **Territorio:** Opcional exclusividad (50% premium).
- **Aplicable a:** Consultoras, agencias digitales, SaaS builders, educadores.

---

## 3. Contenido Licenciado
**Metodología:**
- Discovery: Definición de MVP, user stories, wireframes.
- Tech decision: Stack selection (React, Flutter, custom).
- Desarrollo: Frontend, backend, integraciones, testing.
- Deployment: Hosting (Vercel, AWS, Firebase), monitoring.
- Post-launch: Analytics, user feedback, iteraciones.

**Incluido:**
- Boilerplate starter (Next.js, React + API).
- Componentes UI reutilizables (Tailwind).
- Integration templates (APIs, webhooks, payments).
- Testing framework setup.
- Deployment playbook (AWS, Vercel, Firebase).
- Analytics y monitoring setup.

---

## 4. Personalización Permitida (hasta 50%)
El cliente PUEDE:
- Elegir tech stack (React, Flutter, etc.).
- Diseño y branding 100% custom.
- Integraciones específicas.
- Lógica de negocio propia.
- Monetización propia (ads, subscription, API).

El cliente NO PUEDE:
- Vender boilerplate como propio.
- Usar componentes sin atribución.
- Remover referencias de calidad.

---

## 5. Certificación de Desarrolladores
**Requisitos:**
1. Experiencia full-stack (2+ años).
2. Capacitación MetodologIA: 3 jornadas (COP 5M).
3. Evaluación: Desarrollar app prototipo en 2 semanas.
4. Recertificación anual (4 horas, COP 2M).

---

## 6. Modelo Económico
| Concepto | Monto |
|----------|-------|
| Licencia anual | COP 25M |
| Certificación desarrollador | COP 5M |
| Recertificación anual | COP 2M |
| Dev por app (estimado) | COP 30M-80M |
| Royalty | 5% ingresos/app |

**Mínimo:** COP 25M/año.
**Modelo:** Licencia + dev + royalty compartida.

---

## 7. Control de Calidad
- **Code review:** Arquitectura, best practices, seguridad.
- **Métricas:** Performance (Lighthouse 90+), security, UX.
- **Auditoría anual:** Apps en producción.
- **Evaluación:** Anual de desarrollador.

---

## 8. Soporte y Materiales
**Incluido:**
- Boilerplates actualizados (GitHub).
- Componentes UI library (Storybook).
- Integration templates.
- Deployment guides.
- Helpdesk técnico (48h).
- Comunidad de desarrolladores.
- Actualizaciones de dependencias.

**Opcional:**
- Co-development.
- Mentoring de desarrollador.
- Optimization y scaling.

---

## 9. Territorios y Exclusividad
- **Default:** No exclusivo.
- **Con exclusividad:** +50% (COP 37.5M/año).

---

## 10. Términos de Licencia
- **Vigencia:** 2 años, renovación automática.
- **Cancelación:** 90 días aviso.
- **Rescisión:** 30 días si incumplimiento.
- **Apps:** Propiedad intelectual del cliente.

# TEC-01 — Asistentes IA (Personas)
## Documento Canónico | Segmento: PERSONAS

**Código:** TEC-01-PERSONAS | **Versión:** 1.0 | **Fecha:** 2026-03-24
**Segmento:** Personas (Individuos, self-pay)

---

## 1. Ficha Rápida
**Servicio de desarrollo personalizado** de asistentes IA para profesionales individuales.

| Aspecto | Detalle |
|--------|---------|
| **Público** | Profesionales, consultores, creadores independientes |
| **Alcance** | 1-2 asistentes personalizados |
| **Inversión** | COP 800K-5M (proyecto) |
| **Tiempo** | 2-4 semanas |
| **Tecnología** | GPTs, OpenAI API, embeddings, RAG simple |
| **Casos de uso** | Asistente personal, coach de escritura, asesor |
| **Soporte** | 3 meses de updates, luego a demanda |

---

## 2. Modelo de Servicio
- **Proyecto único:** No es licencia, es desarrollo custom.
- **Scope limitado:** 1 LLM + 1 integración + 1 data source.
- **Propósito:** Herramienta de trabajo personal, no producto comercial.
- **Propiedad:** Cliente es propietario del asistente.
- **Modelo de pago:** Fijo por proyecto, no royalties.

---

## 3. Contenido del Proyecto
**Descubrimiento (1 semana):**
- Entrevistas sobre workflows.
- Definition de MVP.
- Tech stack decision.

**Desarrollo (2-3 semanas):**
- Arquitectura simple (GPT + retrieval).
- Entrenamiento con datos personales (CV, docs, notas).
- Integración (Slack, WhatsApp, o interfaz web simple).
- Testing básico.

**Entrega:**
- Asistente funcional, listo para usar.
- Documentación de uso.
- 3 meses de soporte incluido.

---

## 4. Opciones de Asistentes
**Opciones populares:**
- **Coach de escritura:** Feedback en borradores, sugerencias de mejora.
- **Asesor de negocios:** Analiza planes, sugiere estrategias.
- **Asistente de investigación:** Resume artículos, busca información.
- **Gestor de proyectos personal:** Ayuda a organizar tareas, reminders.
- **Entrenador personal:** Coach de productividad, hábitos, metas.

**Presupuesto por opción:**
- Básico (GPT + web): COP 800K-1.5M
- Intermedio (GPT + integración): COP 1.5M-3M
- Avanzado (RAG + datos + multiple channel): COP 3M-5M

---

## 5. Especificaciones Técnicas
**Stack estándar:**
- LLM: OpenAI GPT-4 o Claude Opus.
- Retrieval: Simple embeddings (Pinecone o local).
- Interfaz: Slack bot, WhatsApp, o webapp React simple.
- Hosting: Serverless (AWS Lambda, Google Functions).
- Datos: Incorpora docs, notas, PDFs del usuario.

**Escalabilidad:**
- No prevista (proyecto personal).
- Si desea después, migración a servicio empresarial.

---

## 6. Modelo Económico
| Componente | Costo |
|-----------|-------|
| Básico (GPT + web) | COP 800K-1.5M |
| Intermedio (+integración) | COP 1.5M-3M |
| Avanzado (+RAG +datos) | COP 3M-5M |
| Soporte 3 meses | Incluido |
| Soporte post-3 meses | COP 200K/mes |

**Pago:** 100% adelanto. No hay royalties.

---

## 7. Proceso de Compra
1. **Consulta inicial:** Contacto gratuito (30 min) para definir scope.
2. **Propuesta:** MetodologIA sugiere opción y presupuesto.
3. **Confirmación:** Cliente firma SOW.
4. **Desarrollo:** 2-4 semanas de trabajo.
5. **Entrega:** Asistente listo, documentación.

---

## 8. Limitaciones y Alcance
- **Un usuario:** Asistente es para uso personal, no compartible.
- **Límite de requests:** ~100/día (en tier básico).
- **Datos confidenciales:** Cliente mantiene control, no compartimos con MetodologIA.
- **Costo de LLM:** Cliente paga uso de OpenAI/Claude (aprox COP 50K/mes).

---

## 9. Términos y Soporte
- **Propiedad:** Cliente es propietario 100%.
- **Soporte:** 3 meses incluido. Post-3 meses, contratos de mantenimiento.
- **Actualización:** LLM se mantiene en versión actual.
- **No incluye:** Expansión, nuevas integraciones, incremento de escala.

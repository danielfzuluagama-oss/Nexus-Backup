## 2. Definición y Alcance

El Bootcamp BC-03 PERSONAS capacita profesionales en métodos de productividad e inteligencia organizacional (Agile mindset, Getting Things Done, Personal Knowledge Management), resultando en sistemas personales sostenibles, menos estrés, más focus.

**Alcance específico:**
- Agile para individuos: Sprints personales, iteración rápida, retrospectivas
- Getting Things Done (GTD): Captura → Clarify → Organize → Reflect → Engage
- Personal Knowledge Management (PKM): Sistema Zettelkasten, note-taking, conexiones
- Time & energy management: Calendario de energía, deep work blocks, boundary-setting
- Tools integration: Notion, Obsidian, Todoist, Google Workspace en ecosystem cohesivo

## 6. Proyecto Capstone

**Tipo:** Personal System Design + 8-week Implementation Plan

**Requisito:**
Diseñar e implementar sistema personal integrado (Agile + GTD + PKM) documentado con:
- Inbox capture + clarification process (donde todo va)
- Weekly review ritual (30min, replicable)
- PKM structure (cómo conectas ideas, knowledge evoluciona)
- Calendar strategy (deep work, meetings, boundaries)
- Dashboard personal (KPIs tracked: hours liberated, tasks completed, energy)

**Ejemplo:** "Sistema personal integrado para consultor multi-cliente: Captura centralizada en Notion → GTD processing → PKM en Obsidian por cliente → Weekly review 90min → Deep work blocks 10-12h daily → Dashboard tracking hours liberated + client satisfaction."

**Criterios de evaluación:**
- Sustainability: ¿Sistema survive 8 weeks de ejecución? (>80% compliance)
- Clarity: Documentación que alguien más entienda
- Results: Horas liberadas, task completion rate, energy/satisfaction
- Adaptability: Cómo sistema evoluciona (quarterly reviews)

**Portabilidad:** Notion template (shareable), YouTube video tutorial (personal workflow), blog post (lessons learned)

## 2. Definición y Alcance

El Bootcamp BC-05 PERSONAS capacita no-technical emprendedores en crear apps profesionales usando no-code platforms (Bubble, FlutterFlow, Airtable, Make), lanzar al mercado, y monetizar sin escribir una línea de código.

**Alcance específico:**
- No-code platform mastery: Bubble (backend+frontend), FlutterFlow (mobile), Airtable bases
- Database + logic: Data modeling, workflows, automations, integrations
- Design + UX: Figma basics, Webflow, polish for launch
- Deployment + DevOps: Hosting, domains, scaling, cost optimization
- Business + launch: MVP validation, pricing, go-to-market, metrics
- Monetization models: SaaS, marketplace, service businesses powered by apps

## 5. Arquitectura Curricular (3 semanas)

### Semana 1: No-code Platform Fundamentals + Design
- **Martes:** Bubble fundamentals (editor, components, data types) | First app: Simple Todo
- **Jueves:** Database design (relational modeling without SQL) | Data types, relationships, workflows
- **Sábado:** Design thinking + Figma crash course | Wireframing + prototyping + mockups

### Semana 2: Intermediate Features + Integrations + Multi-Platform
- **Martes:** Advanced Bubble (responsive design, progressive disclosure, mobile-first)
- **Jueves:** Integrations: Stripe, Airtable, APIs, webhooks | Payment processing + authentication
- **Sábado:** FlutterFlow intro (mobile apps) | Cross-platform considerations

### Semana 3: Polish + Launch + Monetization
- **Martes:** Deployment + custom domains + scaling | Performance optimization
- **Jueves:** MVP validation + business model workshop | Pricing strategy + go-to-market
- **Sábado:** Capstone app presentations + investor panel | Launch support planning

## 6. Proyecto Capstone

**Tipo:** 2-3 No-code apps + Launch MVP

**Requisito:**
Crear 2-3 working apps que demuestren platform mastery:
- App 1 (Bubble): Full-featured app con database, integrations, user auth
- App 2: Either advanced Bubble OR mobile (FlutterFlow)
- App 3 (optional): Specialized (marketplace, SaaS, internal tool)

**Ejemplo 1:** "Freelancer marketplace: Browse services → search/filter → booking → payment (Stripe) → ratings. Deployed on custom domain, 100 beta users launched."

**Ejemplo 2:** "Online course platform: Create courses → manage students → payments → certificate generation. Using Bubble + Airtable + email integrations."

**Criteria:**
- Funcionalidad (40%): Does app work? Professional quality?
- Business viability (30%): ¿Hay demand? ¿Pricing model claro?
- Launchability (20%): Deployable, documented, runnable por otros
- Learning demonstration (10%): Capstone reflects skills learned

**Portabilidad:** Live URL, video demo (5min), pitch deck (investor-ready), business model canvas

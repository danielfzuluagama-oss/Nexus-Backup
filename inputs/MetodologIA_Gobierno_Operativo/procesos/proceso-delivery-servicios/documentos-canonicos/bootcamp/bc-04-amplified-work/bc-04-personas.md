## 2. Definición y Alcance

El Bootcamp BC-04 PERSONAS capacita makers en creación de custom GPTs, AI agents, y herramientas inteligentes para multiplicar su impacto y monetización, sin requiere PhD en ML.

**Alcance específico:**
- Custom GPTs: CreationLLM con knowledge bases, custom instructions, integrations
- AI agents: OpenAI agents framework, autonomous workflows, memory, reasoning
- APIs + integrations: Webhooks, Zapier, Make, custom integrations
- Fine-tuning light: Prompt engineering avanzado, retrieval optimization
- Building in public: Distribution, personal branding, community engagement
- Monetization: Patterns para vender GPTs, agents, o servicios alrededor

## 6. Proyecto Capstone

**Tipo:** 2-3 Deployable Custom GPTs/Agents + Building in Public

**Requisito:**
Crear mínimo 2 custom GPTs o 1 AI agent completamente funcional que:
- Soluciona un problema real (propio negocio, cliente, o público)
- Tiene knowledge base custom o API integration
- Está documentado + deployable por otros
- Tiene públicamente un post/Twitter thread sobre aprendizaje

**Ejemplo 1:** "Sales Email Generator GPT: Training data de tus mejores sales emails → personalized outreach templates → integrated en Pipedrive. Tweet: 'Built a sales email GPT that generated 3 deals worth COP 30M in 2 weeks.'"

**Ejemplo 2:** "Code Review Agent: Takes codebase → automated code review → suggestions → logged in GitHub. Built with LangChain, deployed on Railway. ProductHunt launch."

**Criterios de evaluación:**
- Funcionalidad (40%): ¿El GPT/agent works as intended?
- Impact (30%): ¿Soluciona problema real? ¿Cuál es ROI?
- Documentation (20%): ¿Otros pueden entender + usar?
- Public reach (10%): ¿Building in public presence?

**Portabilidad:** GitHub repo (código, prompts, docs) + YouTube video (5min demo) + Twitter thread (learnings)

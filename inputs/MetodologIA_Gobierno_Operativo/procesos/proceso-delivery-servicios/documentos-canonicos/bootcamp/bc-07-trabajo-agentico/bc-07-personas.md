## 4. Estructura de Contenido

### Semana 1-2: Fundamentos de Agentes
- Qué es agente AI (vs chatbot, vs API)
- Arquitectura: input → reasoning → action → output
- Frameworks: LangChain, Vercel AI SDK, OpenAI API
- Demo live: construimos bot simple en vivo (30 min)
- Proyecto 1: "Mi primer agente" (chatbot básico)

### Semana 3-4: Reasoning y Decision-Making
- Chain of Thought: cómo estructurar razonamiento
- Function calling: agente que elige qué hacer
- State management: memoria del agente
- Integración APIs: agente que consume datos externos
- Proyecto 2: "Agente que investigación" (busca, sintetiza, reporta)

### Semana 5-6: Multi-Agent Systems
- Coordinación entre agentes (orchestration)
- Especialización: roles del agente
- Comunicación entre agentes
- Patrones: workflow, pipeline, collaborative
- Proyecto 3: "Equipo de agentes" (3+ agentes coordinados)

### Semana 7-9: Productización (Semana Más Crítica)
- Deployment: Lambda, Vercel, Railway (AWS)
- Escalabilidad: qué rompe primero
- Cost optimization: cómo no arruinarse con LLM calls
- Monitoring: logs, errores, performance
- Capstone Project 1: DEPLOY TU PRIMER AGENTE

### Semana 10-12: Monetización y Case Study
- Cómo vender agentes (SaaS, API, custom)
- Pricing: basado en uso, suscripción, project-based
- Marketing: cómo posicionar tu agente
- Security: API keys, data protection, compliance
- Capstone Project 2: SEGUNDO AGENTE (completo, documentado, portfolio-ready)

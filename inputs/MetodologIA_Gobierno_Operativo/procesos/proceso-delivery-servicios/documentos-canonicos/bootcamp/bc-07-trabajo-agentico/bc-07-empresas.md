## 2. Audiencia del Segmento

### Perfil primario
- Directores técnicos buscando transformación AI
- Equipos de desarrollo (10-20 personas)
- Startups Series A/B (product roadmap AI-first)
- Empresas con datos pero sin capacidad AI interna
- Líderes de innovación (necesitan showcase)

### Dolor/necesidad
- "Tenemos demanda de AI pero equipo no sabe construir"
- "Competidores tienen agentes; nosotros no"
- "Invertimos en AI pero no vemos ROI claro"
- "Quiero probar agentes en casos reales sin riesgo"
- "Mi equipo necesita upskilling urgente"

### Nivel de preparación
- Acceso a datos/APIs de empresa (crítico)
- Equipo tech con Python intermedio mínimo
- Director/PM disponible para priorización (2h semana)
- Presupuesto AI (API keys, compute, tools)
- Disposición: 5h semanales por participante

## 3. Propuesta de Valor Diferenciada

**Para el segmento EMPRESAS:**
- Agentes específicos: resuelven problemas reales de empresa
- ROI medible: métrica before/after, cost savings, automation gains
- Transferencia: equipo interno capacitado para mantener/mejorar
- Documentación: arquitectura, procesos, best practices (tu IP)
- Executive story: pitch para board/investors sobre capacidad AI
- 6 meses soporte: post-bootcamp, evoluciones agentes en producción

**Diferenciador:**
- No es "capacitación teórica"; es transformación operativa
- Agentes de verdad, no demostraciones: costo real, impacto real
- Tu equipo da la dirección (MetodologIA facilita construcción)
- Certificación empresarial: reconocimiento de capacidad AI interna

## 4. Estructura de Contenido

### Semana 0: Diagnóstico Empresa + Kick-off
- Entrevista ejecutiva + técnica (qué problemas resolver)
- Auditoría: datos disponibles, APIs, infraestructura
- Selección 3-5 casos de uso (priorizar por ROI x facilidad)
- Kick-off presencial (16h): alineación + setup ambiente

### Semana 1-2: Fundamentos + Caso 1
- Arquitectura agentes (en contexto de empresa)
- Setup: data pipelines, API integrations
- Proyecto 1: Agente para caso más crítico/fácil
- Target: funcional, integrando datos reales

### Semana 3-4: Reasoning + Caso 2
- Decision-making en agentes
- Function calling + integración sistemas empresa
- Proyecto 2: Agente para caso 2 (probablemente más complejo)
- Multi-agent coordination si aplica

### Semana 5-6: Productización + Monitoreo
- Deployment en infraestructura empresa
- Cost optimization (LLM calls costosos)
- Monitoring: logs, errores, performance
- Testing: reliability, edge cases

### Semana 7-10: Escala + Casos 3+
- Escalabilidad: qué rompe con volumen
- Automatización de retraining (si datos cambian)
- Integración completa con sistemas existentes
- Proyecto 3+: agente adicional O versión escalada

### Semana 11-12: ROI Measurement + Executive Handoff
- Métricas: tiempo ahorrado, errores reducidos, costo
- Dashboard ejecutivo: visualización impacto
- Documentación: cómo el equipo mantiene/evoluciona
- Capstone: presentación board + plan de escalabilidad

## 5. Entregables del Segmento

1. **3+ Agentes Deployed en Producción**
   - Agente 1: Problema crítico de empresa
   - Agente 2: Caso complementario
   - Agente 3+: Extensión o automación adicional
   - Todos: metrics, monitoring, alerting configurado

2. **ROI Measurement y Executive Summary**
   - Before/after: tiempo, costo, calidad
   - Dashboard: visualización KPIs clave
   - Executive summary: 5 páginas, pitch-ready
   - Business case: para aprovechar inversión

3. **Documentación Completa**
   - Architecture: diagramas, decisiones, trade-offs
   - Runbook: cómo operar agentes, troubleshoot, escalar
   - Código: limpio, comentado, versionado en GitHub
   - API documentation: para integraciones futuras

4. **Plan de Sostenimiento (6 meses)**
   - Quién mantiene cada agente
   - Cómo evolucionan (nuevos LLMs, nuevos casos)
   - Retraining: si datos cambian
   - Roadmap: qué construir después

5. **Certificado Colectivo**
   - Diploma: "Trabajo Agéntico — Nivel Empresarial"
   - Reconocimiento: en LinkedIn, sitio MetodologIA
   - Ventaja: candidatos futuros ven capacidad AI comprobada

6. **Comunidad Cerrada (12 meses post-bootcamp)**
   - Slack: otros equipos corporativos con agentes
   - Sesiones trimestrales: evoluciones, troubleshooting, trends
   - Soporte directo: 48h para preguntas técnicas
   - Networking: CTOs, VPs Innovation, colaboraciones

## 8. Operación y Logística

### Facilitador
- MetodologIA Certified AI + 7+ años desarrollo + producción
- Expertise: LangChain, OpenAI, Claude API, Vercel/AWS deployment
- Ha deployado 5+ agentes en empresas (casos complejos)
- Fluent en arquitectura empresa, integraciones, compliance
- Capacitación: 50h prep (diagnosticador, diseño) + 60h vivo + 80h soporte

### Diagnosticador (Semana 0)
- Senior facilitador + data/infrastructure engineer
- Auditoría completa: datos, APIs, sistemas existentes
- Priorización: qué 3-5 agentes construir
- Entrega: blueprint técnico + timeline ejecutable

### Champion Interno (Identificado Semana 1)
- Tech lead del equipo (responsable del equipo)
- Liaised con facilitador (timeboxing, escalaciones)
- Capacitado para mantener post-bootcamp
- 6 meses soporte directo (MetodologIA + champion)

### Plataforma
- Zoom (síncronas, grabadas)
- GitHub (repos, code review, CI/CD)
- Slack workspace (cerrado, equipo + facilitador)
- Notion (hub, architecture docs, roadmap)
- Herramientas empresa (Salesforce, DataDog, etc.)
- Compute: AWS/Vercel account (empresa paga uso)

### Timing
- Semana 0: diagnóstico presencial 3 días (kick-off)
- Semanas 1-4: 2 sesiones semanales sincrónicas (4h total)
- Semanas 5-10: 1 sesión semanal + project work (5h total)

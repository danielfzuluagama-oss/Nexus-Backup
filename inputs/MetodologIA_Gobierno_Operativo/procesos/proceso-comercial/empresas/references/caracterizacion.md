# Caracterización de Personas: Empresas (B2B)

> [!NOTE]
> **Propósito:** Definir los perfiles de decisión y uso dentro de grandes organizaciones para alinear la narrativa comercial y los hitos del Studio.

---

## 1. Matriz User / Buyer / Customer

| Dimensión | User (El Practicante) | Buyer (El Decisor) | Customer (La Organización) |
| :--- | :--- | :--- | :--- |
| **Rol Típico** | Project Manager / Ops Lead | Director de Área / CXO | Entidad Mid-Market / Enterprise |
| **Dolor Crítico** | Caos operativo, fricción manual. | Baja visibilidad de KPIs, riesgos. | Silos de información, falta de SOTA. |
| **Valor Percibido** | Simplicidad, superpoderes de IA. | Predictibilidad, ahorro de costos. | Soberanía de datos, ventaja competitiva. |
| **Output Notebook** | Guías de implementación, SOPs. | Reportes de Impacto, ROI Dashboards. | Foso de inteligencia (Moat). |

---

## 2. Arquetipos Clave

### El "Orquestador Frustrado" (User)
- **Perfil:** Experto técnico que siente que la organización se mueve lento.
- **Canal:** LinkedIn, repositorios de GitHub, webinars especializados.
- **Engagement:** "Enséñame cómo automatizar este cuello de botella".

### El "Estratega de Eficiencia" (Buyer)
- **Perfil:** Responsable de P&L que necesita resultados trimestrales.
- **Canal:** Recommendations de red de confianza, reportes sectoriales.
- **Engagement:** "Muéstrame el Business Case y el tiempo de recuperación de inversión".

---

## 3. Best Practices de Abordaje

- **Diferenciación de Contenido:** Al User se le envía contenido técnico (Juegos 0-10); al Buyer se le envía contenido de visión (Service Blueprint).
- **Consistencia:** Ambos deben ver la firma visual Neo-Swiss para generar confianza institucional.

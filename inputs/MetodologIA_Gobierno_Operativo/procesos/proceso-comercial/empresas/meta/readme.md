# Meta-Información: Proceso Comercial Empresas (B2B)

**Propósito:** Contiene las definiciones ontológicas y de proceso para la venta consultiva a empresas.

## Estructura

-   **`assets/`**: Documentos operativos listos para usar.
    -   `contrato-marco-servicios-b2b.md`: Precontrato canónico.
    -   `orden-servicio-b2b.md`: Plantilla de OdS.
    -   `spoc-*.md`: Fichas de puntos de contacto.
-   **`meta/`**: Definiciones y grafos de conocimiento.
    -   `knowledge-graph.md`: Ontología del proceso en Mermaid.
    -   `readme.md`: Este archivo.

## Glosario Clave

-   **Precontrato Marco:** Acuerdo de intenciones previo a la constitución jurídica.
-   **OdS (Orden de Servicio):** Instrumento para activar servicios específicos.
-   **SPoC:** Punto único de contacto para la operación.

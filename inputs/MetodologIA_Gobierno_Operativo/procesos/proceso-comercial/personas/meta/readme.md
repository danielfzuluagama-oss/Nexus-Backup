# Meta-Información: Proceso Comercial Personas (B2C)

**Propósito:** Contiene las definiciones ontológicas y de proceso para la venta directa a personas (B2C).

## Estructura

-   **`assets/`**: Documentos operativos listos para usar.
    -   `contrato-compromiso-pago-b2c.md`: Acuerdo de pago y servicio.
    -   `pagare-servicio-b2c.md`: Garantía de pago.
-   **`meta/`**: Definiciones y grafos de conocimiento.
    -   `knowledge-graph.md`: Ontología del proceso en Mermaid.
    -   `readme.md`: Este archivo.
    -   `auditoria-conformidad-personas.md`: Checklist de calidad.

## Glosario Clave

-   **Participante:** Persona natural que recibe el servicio educativo.
-   **Compromiso de Pago:** Acuerdo vinculante sobre cronograma y montos.
-   **Pagaré:** Título valor que respalda la obligación financiera.

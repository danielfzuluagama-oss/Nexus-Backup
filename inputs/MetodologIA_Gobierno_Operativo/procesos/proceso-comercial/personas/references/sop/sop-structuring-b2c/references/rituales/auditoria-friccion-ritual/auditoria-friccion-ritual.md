# Ritual: Friction Audit (Checkout Optimization)

> [!IMPORTANT]
> **Estado:** Sovereign Edition v2.0
> **Cadencia:** Semanal (Metrics Review)
> **Objetivo:** Eliminar cualquier paso que separe el "Deseo" de la "Acción".

## 1. El Protocolo (Gold Checklist)

- [ ] **DRI:** UI/UX Craftsman.
- [ ] **Input:** Data de abandono de carrito / Drop-off.
- [ ] **Output:** Zero-Friction Checkout Plan.

## 2. La Secuencia Metodológica

### Step 1: Cognitive Load Test (Zona Verde)

*¿Es fácil de entender?*

- Navegar el flujo con el cerebro "apagado" (poca atención).
- ¿Hay demasiados campos? ¿Hay distracciones?
- Objetivo: Eliminar ruidos visuales.

### Step 2: Step Count Audit (Zona Ambar)

*¿Podemos hacerlo en menos pasos?*

- Contar cada click necesario desde el "Click to Buy" hasta el "Thanks Page".
- Cualquier flujo de > 3 pasos es un error sistémico.

### Step 3: Solution Design (Zona Roja)

*Implementar dopamina inmediata.*

- Diseñar el "Success Confirmation" (Aha Moment instantáneo).
- Asegurar que el acceso al producto sea inmediato tras el pago.

## 3. Definition of Done (DoD)

El ritual termina cuando:

- [ ] Se ha eliminado al menos 1 paso innecesario.
- [ ] El tiempo medio de checkout se ha reducido.
- [ ] El test de "un solo click" ha sido validado.

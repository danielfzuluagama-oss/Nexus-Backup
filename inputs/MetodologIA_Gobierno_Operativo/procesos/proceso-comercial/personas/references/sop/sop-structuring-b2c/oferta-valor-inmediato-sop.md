# SOP: Immediate Value (Frictionless Structuring)

> [!IMPORTANT]
> **Estado:** Sovereign Edition v2.0
> **Objetivo:** Convertir el "Ancla Emocional" en una transacción sin culpa (Guilt-free).
> **Output:** Transacción + Dopamine Hit.

## 1. Rigor Metodológico (Gold Checklist)

- [ ] **DRI:** Product Owner.
- [ ] **Methodology:** Frictionless Design + Value Stacking.
- [ ] **Ritual:** [auditoria-friccion-ritual.md](./references/rituales/auditoria-friccion-ritual/auditoria-friccion-ritual.md) (Friction Audit).
- [ ] **Ontología:** El checkout es parte del producto, no una barrera.

## 2. El Marco de Trabajo: The Value Stack

| Capa | Definición | Ejemplo |
| :--- | :--- | :--- |
| **Core** | Lo que compran. | "Curso de Inversión". |
| **Bonus** | Lo que elimina riesgo. | "Plantilla de Excel lista para usar". |
| **Urgency** | Lo que fuerza la acción. | "Precio especial por 24h". |
| **Trust** | Lo que da permiso. | "Garantía de 30 días sin preguntas". |

## 3. Guía de Ejecución (Sovereign Flow)

### Fase A: The Setup (Zona Verde)

*La página de venta (LP).*

- **Headline:** Habla a la Identidad ("Conviértete en Inversor").
- **Body:** Habla al Ancla Emocional ("Deja de temer por tu futuro").
- **CTA:** Claro y directo ("Empieza Hoy").

### Fase B: The Checkout (Zona Ambar)

*Zona de No-Pensar.*

- Solo pedir lo esencial: Email + Tarjeta.
- Mostrar sellos de seguridad.
- Recordar la garantía (Risk Reversal).

### Fase C: The First Value (Zona Roja)

*El primer minuto post-compra.*

- No mostrar "Gracias por tu compra".
- Mostrar "Bienvenido, aquí está tu primer paso".
- Entregar una victoria rápida inmediata (e.g., un diagnóstico, un video de bienvenida).

## 4. Definition of Done (DoD)

Una estructura es válida sí y solo sí:

- [ ] El usuario puede comprar en <2 minutos.
- [ ] El Value Stack supera 10x el precio percibido.
- [ ] El primer uso ocurre inmediatamente después del pago.

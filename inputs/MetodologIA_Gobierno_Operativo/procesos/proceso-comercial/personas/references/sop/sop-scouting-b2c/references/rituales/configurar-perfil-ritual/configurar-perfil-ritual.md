# Ritual: Configurar Perfil B2C

- **Versión:** v1.0.0
- **Objetivo:** Alistar el entorno de seguimiento para un nuevo cohorte.

## Paso a Paso (8-10 Pasos)

1. **Identificar**: Definir el arquetipo objetivo (ej. Freelance, CEO).
2. **Configurar**: Crear vista personalizada en el tablero de Adquisición.
3. **Mapear**: Asociar el Lead Magnet con el segmento.
4. **Automatizar**: Activar alertas de nuevas señales para este perfil.
5. **SOTA**: Revisar el estado del arte para este segmento.
6. **Briefing**: Sincronizar al equipo sobre los dolores del arquetipo.
7. **Probar**: Simular la entrada de un lead de prueba.
8. **Firmar**: Validar configuración en `meta/`.

---
**Standard**: Moat v2.1.0

# SOP: Success & Viral Loop (Referral Engineering)

> [!IMPORTANT]
> **Estado:** Sovereign Edition v2.0
> **Objetivo:** Transformar la satisfacción en crecimiento orgánico.
> **Output:** Viral Coefficient K > 1.

## 1. Rigor Metodológico (Gold Checklist)

- [ ] **DRI:** Community Lead.
- [ ] **Methodology:** Product-Led Growth (PLG).
- [ ] **Ritual:** [activar-viralidad-ritual.md](./references/rituales/activar-viralidad-ritual/activar-viralidad-ritual.md) (Viral Loop Activation).
- [ ] **Ontología:** El mejor marketing es un cliente transformaado.

## 2. El Marco de Trabajo: The Viral Engine

| Componente | Definición | Ejemplo |
| :--- | :--- | :--- |
| **Payload** | Lo que se comparte. | "Acceso VIP", "Descuento", "Status". |
| **Trigger** | Cuándo se comparte. | Justo después de recibir valor. |
| **Channel** | Por dónde se comparte. | WhatsApp, LinkedIn, Email. |
| **Incentive** | Por qué se comparte. | Altruismo ("Ayudar") o Ego ("Lucir bien"). |

## 3. Guía de Ejecución (Sovereign Flow)

### Fase A: Verify Value (Zona Verde)

*No pidas nada si no has dado nada.*

- Monitorear uso del producto.
- Esperar al "Aha! Moment" (e.g., Primera exportación exitosa).
- Validar satisfacción (NPS, Review interna).

### Fase B: Contextual Ask (Zona Ambar)

*La invitación natural.*

- "Vemos que estás teniendo resultados increíbles."
- "¿Conoces a alguien más que necesite esto?"
- Facilitar el compartir (Pre-filled message).

### Fase C: The Gratitude Loop (Zona Roja)

*Reconocer al promotor.*

- Cuando el referido se une, notificar al promotor.
- "Has ayudado a X a empezar."
- Reforzar su identidad de "Líder / Experto".

## 4. Definition of Done (DoD)

Un ciclo viral es válido sí y solo sí:

- [ ] Se dispara automáticamente tras el éxito.
- [ ] La fricción para compartir es casi nula.
- [ ] El "Payload" ofrece valor real al receptor, no es spam.

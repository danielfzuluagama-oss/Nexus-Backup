# Ritual: Viral Loop (Referral Trigger)

> [!IMPORTANT]
> **Estado:** Sovereign Edition v2.0
> **Cadencia:** Automática (Post-Aha Moment)
> **Objetivo:** Que el usuario traiga a su "Tribu".

## 1. El Protocolo (Gold Checklist)

- [ ] **DRI:** Growth Hacker / Automation Lead.
- [ ] **Input:** Usuario que acaba de lograr su primer "Small Win".
- [ ] **Output:** Referral Link compartido + Recompensa activada.

## 2. La Secuencia Metodológica

### Step 1: Aha Moment Detection (Zona Verde)

*Capturar el pico de dopamina.*

- Detectar cuando el usuario completa su primer módulo o logra su primera meta.
- El ritual debe lanzarse exactamente en ese momento, no antes.

### Step 2: Reward Matching (Zona Ambar)

*¿Qué le damos?*

- Ofrecer una recompensa que multiplique su éxito (Ej: Un capítulo extra, un token de IA).
- Evitar descuentos simples; buscar recompensas de "Status".

### Step 3: Trigger Launch (Zona Roja)

*Hacerlo irresistible.*

- Lanzar el popup o el email de "Regala esto a 3 amigos y gana X".
- Facilitar el compartido con un solo click (WhatsApp/LinkedIn).

## 3. Definition of Done (DoD)

El ritual termina cuando:

- [ ] Se ha enviado el trigger de referidos.
- [ ] El link de referido está activo y trackeado.
- [ ] Se ha registrado el primer clic de un referido del usuario.

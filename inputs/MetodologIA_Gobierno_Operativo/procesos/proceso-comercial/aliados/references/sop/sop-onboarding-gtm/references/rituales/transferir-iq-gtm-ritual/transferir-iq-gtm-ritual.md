# Ritual: Transferir IQ de Alianza
- **Versión:** v2.1.0
- **Objetivo:** Habilitar al socio con los activos de inteligencia y prompts del ecosistema MetodologIA.

## Paso a Paso (8-10 Pasos)
1. **Configurar**: Crear el NotebookLM dedicado para el aliado en el espacio de partners.
2. **Cargar**: Importar los 5 documentos core de MetodologIA (L1-L3) al Notebook.
3. **Sectorizar**: Subir fuentes específicas de la industria del aliado para contextualizar la IA.
4. **Sincronizar**: Ejecutar la primera query conjunta sobre el "Diferenciador Neo-Swiss".
5. **Generar**: Crear el primer artefacto (Audio o Reporte) en Studio de forma asistida.
6. **Promptear**: Entregar al aliado el catálogo de prompts de alta densidad oficial.
7. **Entrenar**: Explicar la lógica de "Input-Only" para evitar alucinaciones en Studio.
8. **Asignar**: Definir el primer caso práctico real que el aliado debe resolver solo.
9. **Calendario**: Establecer las fechas de seguimiento de las semanas 1, 2 y 4.
10. **Activar**: Confirmar acceso total del aliado al repositorio de herramientas.

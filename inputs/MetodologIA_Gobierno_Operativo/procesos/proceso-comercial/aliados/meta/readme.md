# Meta-Información: Proceso Comercial Aliados (GTM)

**Propósito:** Contiene las definiciones ontológicas y de proceso para la gestión de alianzas estratégicas (Go-To-Market).

## Estructura

-   **`assets/`**: Documentos operativos listos para usar.
    -   `contrato-marco-alianza-gtm.md`: Acuerdo base de alianza.
    -   `orden-servicio-gtm.md`: Activación de oportunidades conjuntas.
    -   `portafolio-servicios-2026.md`: Oferta comercial vigente.
-   **`meta/`**: Definiciones y grafos de conocimiento.
    -   `knowledge-graph.md`: Ontología del proceso en Mermaid.
    -   `readme.md`: Este archivo.
    -   `insights.md`: Memorias y aprendizaje del modelo de aliados.

## Glosario Clave

-   **Aliado GTM:** Socio estratégico para reventa o referencia.
-   **Revenue Share:** Modelo de partición de ingresos.
-   **Embajador:** Aliado persona natural (marca personal).

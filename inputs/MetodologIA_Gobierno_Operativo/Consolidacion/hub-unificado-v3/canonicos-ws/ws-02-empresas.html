Segmento: Empresas (B2B — Corporativo)

Precio canónico: COP 3,000,000 (hasta 20 participantes)

Duración: 3 horas

Modalidad: Virtual sincrónico (default) | Presencial on-site (a solicitud)

1. Ficha Rápida ▼

Objetivo corporativo: Estandarizar cómo tu equipo usa IA; crear librería de prompts organizacionales reutilizable

Audiencia ideal: Equipos de marketing, análisis, operaciones, customer success, contenido

Outcome esperado: 10+ prompts documentados + guía de gobernanza interna

Prerequisitos: Acceso activo a ChatGPT, Claude, Gemini (o equivalente)

Certificación: Constancia de asistencia + acceso a librería de prompts privada

2. Definición y Alcance ▼

Este taller enseña técnicas avanzadas de prompting (chain-of-thought, few-shot, role-play, etc.) con énfasis en estandarización corporativa. El objetivo es que equipos dejen de improvisar prompts y trabajen con plantillas documentadas, versionadas, reutilizables.

Alcance:

Fundamentos: anatomía de un prompt efectivo
Técnicas avanzadas: chain-of-thought, few-shot learning, rol-playing
Prompt engineering para casos de uso corporativos
Creación de librería interna (Notion, Obsidian, etc.)
Documentación y versionado de prompts
Evaluación de calidad output (métricas de efectividad)

Fuera de alcance:

Fine-tuning de modelos (consultoría técnica)
APIs y integración programática
Construcción de aplicaciones (requiere desarrollo)
3. Audiencia Corporativa ▼

Perfil primario: Especialistas de contenido, analistas, customer success managers

Perfil secundario: Marketing, operaciones, recursos humanos, comunicación interna

Tamaño típico: 12-20 participantes (equipo multifuncional)

Nivel técnico: Intermedio (han usado ChatGPT, quieren mejorar)

4. Propuesta de Valor Empresarial ▼

✓ Consistencia operativa: Todos usan los mismos prompts; mismo nivel de calidad

✓ Reducción de tiempo: No reimventar la rueda cada vez

✓ Reutilización: Una vez creado, el prompt funciona para siempre

✓ Escalabilidad: Nuevas personas aprenden y aplican estándares

✓ ROI observable: Menos iteraciones, output más rápido y predecible

5. Estructura y Contenido (con contextualización) ▼

Módulo 1: Fundamentos de Prompting Efectivo (45 min)

Anatomía del prompt: instrucción, contexto, formato, restricciones
Modelos mentales: cómo piensan los LLMs
Errores comunes (vaguedad, falta de contexto, mala estructura)
Demostración en vivo con casos reales

Módulo 2: Técnicas Avanzadas (60 min - CONTEXTUALIZADO 30%)

Chain-of-thought: reasoning paso a paso
Few-shot prompting: aprender de ejemplos
Role-playing: definir "personaje" del asistente
Prompt chaining: múltiples pasos conectados
Adaptación: 2-3 casos de uso específicos de tu empresa (marketing, análisis, operaciones)

Módulo 3: Librería Organizacional (35 min)

Estructura de documentación (template estándar)
Versionado y control de cambios
Evaluación de efectividad (métrica simple)
Herramientas recomendadas: Notion, Airtable, GitHub
Governance: quién aprueba, quién publica

Módulo 4: Hands-on + Creación Colaborativa (20 min)

Ejercicio práctico en breakout rooms
Creación de prompt conjunto (tu caso de uso)
Presentación y feedback grupal
6. Entregables Organizacionales ▼

✓ Guía de prompting avanzado: 30 páginas (PDF + editable)

✓ Template de documentación: Para todos los prompts corporativos

✓ Librería inicial: 10 prompts pre-escritos para roles comunes

✓ Checklist de calidad: Evaluar prompts antes de publicar

✓ Playbook de implementación: Cómo rolear la librería en tu equipo

✓ Acceso a repositorio privado: Almacenamiento + versionado (90 días)

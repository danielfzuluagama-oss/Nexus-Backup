Segmento: Aliados (Strategic Co-delivery Partners — TECH REQUIRED)

Duración: 12 semanas (300 horas)

Modalidad: Co-entrega remota + presencial opcional

2. Audiencia del Aliado ▼

Tipo de Aliado ideal

Consultoras de AI/machine learning (transformación AI)
Bootcamps técnicos (Platzi, Le Wagon, Coder House)
Universidades técnicas (programas de extensión)
Academias de ingeniería avanzada
Startups de ed-tech especializadas en AI/dev

Perfil CRÍTICO (no negociable)

Expertise técnica: 3+ años en AI/LLMs, capaces de revisar código complicado
Facilitadores: equipo tech con producción real de agentes
Infraestructura: capacidad de hostear, debugging, troubleshooting
Comunidad: red de developers/builders (no es público masivo)
Alineación: valores de rigor técnico, ética AI, escalabilidad

Dolor/necesidad del Aliado

"Tenemos demanda de AI engineering pero no tenemos curriculum"
"Quiero ofrecer bootcamp top-tier sin crear desde cero"
"Competidor está ofreciendo bootcamps; necesito respuesta"
"Mi red de developers quiere aprender agentes"
3. Propuesta de Valor para Aliado ▼

Lo que recibe el Aliado:

Curriculum AI robusto, actualizado constantemente
Metodología pedagógica probada (learning outcomes claros)
Red global de builders + potential customers para servicios futuros
Certificación MetodologIA (peso en mercado)
QA rigurosa: garantiza calidad = reputación Aliado
Co-evolution: feedback Aliado → innovación MetodologIA

Diferenciador:

No es licencia simple; es partnership técnico
Aliado mantiene 55% ingresos brutos
MetodologIA está muy involucrada (45% = supervisión activa)
Acceso a innovations: nuevas arquitecturas, frameworks, case studies
Network effect: conectado con otros Aliados top-tier

Riesgos Mitigados:

MetodologIA QA rigurosa: evita reputación dañada por bootcamp pobre
Co-delivery: escalabilidad con calidad
Certificación conjunta: responsabilidad compartida
4. Estructura de Co-Entrega (ESPECIALIZADA TECH) ▼

Fase 1: Onboarding del Aliado (12 semanas — MÁS LARGO QUE BC-06)

Assessment técnico: ¿puede el Aliado mantener esto?
Taller avanzado: agentes, producción, scaling (60h)
Entrenamiento facilitadores: 3-4 personas (120h cada)
Incluye: architecture review, code quality, deployment
Live projects: ejercicios reales de 2 semanas
Certification assessment: pueden enseñar esto?
Auditoría infraestructura: ¿tiene compute, APIs, tooling?
Contrato: términos técnicos + IP + quality standards

Fase 2: Piloto Cohort (Semana 0-12)

Aliado entrega con facilitador interno recién certificado
MetodologIA: presencia semanal (supervisa, escalaciones)
Technical review: code commits, architectures
Feedback semanal: pedagogía + content + technical rigor
Auditoría pre-lanzamiento (semana 6): ¿está en track?

Fase 3: Lanzamiento Público (Semana 13+)

Aliado maneja operación (sales, enrollment)
MetodologIA: auditoría cada 2 semanas (no trimestral como BC-06)
Revenue flow: Aliado cobra, envía 45% a MetodologIA (mensual)
Technical escalations: 24h respuesta MetodologIA
Recertificación facilitadores: cada 6 meses (más rigurosa)

Fase 4: Escalabilidad con Calidad (Cada Cohort)

Auditoría rigurosa antes de nueva cohort
NPS mínimo: 8.5/10 (más alto que BC-06)
Technical metrics: code quality, deployment success rate
Innovaciones: MetodologIA comparte features nuevas
Feedback loop: mejora continua, no complacencia
5. Contenido y Personalización ▼

Contenido Base (90% igual en todos lados)

12 semanas: 300 horas estructura idéntica
Slides, code templates, deployment best practices: suministrados
Arquitectura agentes: framework no se modifica
Capstone: estándar (2+ agentes deployed, ROI measurement)

Contextualización del Aliado (10% custom — RESTRINGIDO)

Herramientas: si Aliado tiene preferencia (LangChain vs OpenAI SDK)
Ejemplos locales: industrias específicas del Aliado
Integración: si Aliado tiene customers que necesiten conectar
Language/tone: adaptación a audiencia (pero rigor técnico no cambia)

Restricciones (para mantener calidad)

NO cambiar arquitectura core
NO simplificar para "más fácil"
NO omitir módulos de producción/deployment
NO comprometer en "ética AI" o "cost optimization"

12. Términos Comerciales ▼

Contrato

Duración inicial: 24 meses
Renovación: automática 12 meses a menos que avise 90d antes
Terminación: con causa = 60d para remediar; sin causa = 6 meses notice

Pagos

Setup fee: COP 8M (pago inicial)
Revenue share: 45% ingresos brutos, mensual
Mínimo anual: COP 30M (si <esto, Aliado paga diferencia O termina)
Métodos: transferencia, dentro 15d post-cobro

Confidencialidad

Mutuamente: no revelar financieros, arquitecturas proprietary, clientes
Excepciones: legal, regulatorio, tax
Duración: perpetua post-término contrato

Terminación

Por causa: 60d para remediar (quality issues, financial)
Sin causa: 6 meses notice + wind-down
Consecuencias: Aliado puede continuar cohortes iniciadas (pero no nuevas)

Indemnización

Cada parte responsable por sí misma
MetodologIA: no responsable si Aliado entrega mal
Aliado: no responsable si Metodología cambia framework
Excepto: breach de confidencialidad O IP theft (liable both)

Vigencia

Válido desde 2026-03-24
Revisión anual términos (especialmente $ porque LLMs abaratarse)
Escalation: fórmula basada en inflación + market comp

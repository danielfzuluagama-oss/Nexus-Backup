2. Definición y Alcance ▼

El Bootcamp BC-03 PERSONAS capacita profesionales en métodos de productividad e inteligencia organizacional (Agile mindset, Getting Things Done, Personal Knowledge Management), resultando en sistemas personales sostenibles, menos estrés, más focus.

Alcance específico:

Agile para individuos: Sprints personales, iteración rápida, retrospectivas
Getting Things Done (GTD): Captura → Clarify → Organize → Reflect → Engage
Personal Knowledge Management (PKM): Sistema Zettelkasten, note-taking, conexiones
Time & energy management: Calendario de energía, deep work blocks, boundary-setting
Tools integration: Notion, Obsidian, Todoist, Google Workspace en ecosystem cohesivo
3. Audiencia del Segmento ▼

Perfil primario:

Edad: 28-55 años, +3 años experiencia laboral
Rol: Manager, analista, consultor, emprendedor, creativo, ingeniero
Contexto: Remote/hybrid, múltiples proyectos simultáneos, reuniones excesivas
Motivación: Recuperar enfoque, reducir estrés, ganar time back para familia/health

Circunstancia específica:

Personas que sienten "siempre ocupadas pero nada completado"
Managers que buscan sistema para delegar + confiar

Personas post-burnout que quieren arquitectura preventiva

Restricciones:

Acceso a computadora, email, algunos tools (pueden ser gratuitos)
Zona horaria: América Latina (GMT-5 a GMT-3)
Disposición a experimentar 3 semanas intensas

5. Arquitectura Curricular (3 semanas) ▼

Semana 1: Audit + GTD Fundamentals + Agile Mindset

Martes: Productivity audit (time tracking, energy mapping) | Problemas identificados (meetings, context-switch, procrastination)
Jueves: Getting Things Done overview | Captura y clarification | Inbox zero engineering
Sábado: Agile para individuos | Sprint planning personal | Iteration mindset

Semana 2: PKM + Tools Integration + Time Management

Martes: Personal Knowledge Management (Zettelkasten, atomic notes) | Obsidian/Notion setup
Jueves: Deep work architecture | Calendar strategy (blocks, boundaries, energy mapping) | Meeting optimization
Sábado: Tools integration workshop | Automations (Zapier, IFTTT) | Dashboard personal

Semana 3: System Fine-Tuning + Sustainability + Peer Accountability

Martes: Retrospective personal (what's working, what's not) | Adjustments
Jueves: Sustaining system (weekly review ritual, quarterly calibration) | Peer accountability groups
Sábado: Capstone presentation + panel de productivity leaders reales | Networking | Accountability partners match
6. Proyecto Capstone ▼

Tipo: Personal System Design + 8-week Implementation Plan

Requisito:

Diseñar e implementar sistema personal integrado (Agile + GTD + PKM) documentado con:

Inbox capture + clarification process (donde todo va)
Weekly review ritual (30min, replicable)
PKM structure (cómo conectas ideas, knowledge evoluciona)
Calendar strategy (deep work, meetings, boundaries)
Dashboard personal (KPIs tracked: hours liberated, tasks completed, energy)

Ejemplo: "Sistema personal integrado para consultor multi-cliente: Captura centralizada en Notion → GTD processing → PKM en Obsidian por cliente → Weekly review 90min → Deep work blocks 10-12h daily → Dashboard tracking hours liberated + client satisfaction."

Criterios de evaluación:

Sustainability: ¿Sistema survive 8 weeks de ejecución? (>80% compliance)
Clarity: Documentación que alguien más entienda
Results: Horas liberadas, task completion rate, energy/satisfaction
Adaptability: Cómo sistema evoluciona (quarterly reviews)

Portabilidad: Notion template (shareable), YouTube video tutorial (personal workflow), blog post (lessons learned)

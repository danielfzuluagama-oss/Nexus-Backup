1.3 El Modelo Embajador (Hallazgo Clave)

El sitio web revela que MetodologIA opera un modelo de red de delivery distribuida:

  1. El profesional hace la Ruta (N0-N9) como cliente
  2. Al graduarse de N7 (Empoderamiento) o N9 (Digital Champions), accede al Bootcamp de Certificacion (3 semanas, gratis)
  3. Se convierte en Embajador certificado con licencia de marca
  4. El Embajador entrega servicios MetodologIA (workshops, bootcamps, consultoria) a SUS clientes
  5. German Sepulveda (Chief Ecosystem Officer) gestiona esta red
Gap operativo mayor: El Embajador es el eslabón final de toda la cadena de valor — es el que ENTREGA servicios al mercado. Sin embargo, NO tiene procesos operativos definidos en el ecosistema actual. No hay SOP de certificación de embajador, no hay SOP de delivery por embajador, no hay feedback loops documentados.

4. Eventos de Activacion: Bridge Comercial ↔ Delivery

BRIDGE

4.1 Taxonomia de Eventos de Activacion

Los eventos de activacion son atomos de delivery que funcionan como herramientas comerciales. Son el puente natural entre los dos procesos:

TipoDuracionCostoObjetivoConversion TargetMapea a
Talk30-45minGratisAwareness: "MetodologIA existe"Asistente → registrado a WS/DiagnosticoComercial B2C + B2B
Diagnostico N030min 1:1GratisClarity: "Se donde estoy"Diagnosticado → matriculado N1+Ruta Nivel 0
Taller de Activacion1.5-2hGratis/LowExperience: "Esto funciona"Asistente → matriculado Bootcamp/ProgramaBridge

Decision Arquitectural DA-06: TODO Modulo 1 de cualquier programa es sin costo y sin riesgo. El participante experimenta el valor antes de comprometerse financieramente. Esto alinea con la filosofia MetodologIA: "dar primero, demostrar valor, luego pedir inversion." El funnel es: Talk (gratis) → Diagnostico N0 (gratis) → Taller (gratis) → Modulo 1 (gratis) → Matricula (pago).

4.2 Flujo Completo de Activacion

FUNNEL DE ACTIVACION COMPLETO ================================================ AWARENESS Talk (30min, gratis, online/presencial) Redes sociales / contenido / referidos ↓ ~100 personas expuestas INTERES Diagnostico N0 (30min 1:1, gratis) Taller de Activacion (1.5h, gratis) ↓ ~30 personas interesadas EXPERIENCIA Workshop WS-08 / Modulo 0 (3h, gratis) Modulo 1 de Programa (1 semana, gratis) ↓ ~15 personas experimentan DECISION Follow-up personalizado (7 dias) Resolucion de objeciones ↓ ~5 personas matriculadas (≥20% conversion) ENTREGA Programa/Bootcamp/TecnologIA ↓ EMBAJADOR Certificacion → Entrega servicios → Refiere nuevos ↓ LOOP: El embajador ejecuta el mismo funnel para SUS clientes

6.2 Incoherencias Detectadas

  1. Nivel 8 (Vibe Coding) existe en el sitio como bootcamp pero no tiene proceso ni SOP en el Gobierno Operativo. Deberia estar en catalogo-bootcamps.md como BC-06.
  2. Digital Champions (N9) existe en el sitio como programa elite pero solo hay SOPs para Empoderamiento. Champions necesita su propio set de SOPs o documentar como variante de Programa Elite.
  3. Los 4 C-Levels no tienen roles operativos mapeados en los procesos. Cada C-Level deberia ser owner de verticales especificas:
    • Javier (Empowerment): Programa Elite + Curriculo
    • Daniel (Efficiency): Procesos + TecnologIA + Consultoria
    • German (Ecosystem): Embajadores + Aliados + Comunidad
    • Katherine (Enablement): Workshop + Bootcamp + Experiencia
  4. El Embajador entrega servicios pero no tiene acceso al Gobierno Operativo. Necesita un "Embajador Playbook" que sea el subset de SOPs + Workflows que el embajador necesita para operar.

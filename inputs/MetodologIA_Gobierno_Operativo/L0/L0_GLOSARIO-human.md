# L0 — Glosario para Humanos (Fundamentos)

## 📖 ¿Qué es esto y por qué es tan importante?

En MetodologIA hablamos un idioma propio para ser ultra-precisos. Este glosario es nuestro "diccionario de la casa". Si todos llamamos a las cosas por su nombre, evitamos confusiones y trabajamos el triple de rápido.

**Regla de oro:** Si usas una palabra de esta lista, úsala EXACTAMENTE como dice aquí.

---

## 🏗️ 1. La Jerarquía (¿Qué estamos construyendo?)

| Término | En español simple... |
| :--- | :--- |

| **Ritual** | La forma oficial de hacer algo que se repite. Tiene 10 pasos (Juegos). |
| **SOP** | Una receta de cocina muy específica (el "paso a paso") dentro de un ritual. |

| **Skill** | Instrucciones para la Inteligencia Artificial para que haga el trabajo por ti. |
| **Documento de Proceso** | El "Manual del Jefe". Define quién manda y qué se busca lograr en grande. |

---

## 🚀 2. La Ejecución (¿Cómo trabajamos?)

| Término | En español simple... |
| :--- | :--- |

| **Juego** | Una etapa de un ritual. Vamos del Juego 0 (Plan) al Juego 10 (Éxito). |
| **Gate (Puerta)** | Un control. O pasas con todo perfecto, o te detienes. Es binario (Sí/No). |

| **DoR (Listo para empezar)** | Lo que necesitas tener a la mano ANTES de arrancar. |
| **DoD (Listo para entregar)** | La lista de cosas que deben estar listas para decir "terminé". |

| **AAR (Revisión post-acción)** | 4 preguntas rápidas después de trabajar para aprender qué mejorar. |

---

## 🛡️ 3. La Calidad y el Orden (¿Qué nos hace "Gold"?)

| Término | En español simple... |
| :--- | :--- |

| **Gold Checklist** | La lista de 12 puntos mágicos que todo documento debe cumplir para ser publicado. |
| **DRI / Owner** | La única persona que tiene la última palabra y la responsabilidad total. |

| **Métrica Leading** | Un aviso de que algo va a salir bien o mal *antes* de que pase. |
| **Métrica Lagging** | El resultado final después de que ya terminó el trabajo. |

| **Adversarial+** | Intentar "romper" lo que creamos para ver si resiste problemas reales. |

---

## 🤖 4. Inteligencia Artificial y Confianza

| Término | En español simple... |
| :--- | :--- |

| **Acelerador GenAI** | Un robot (prompt o agente) que te ayuda en una tarea específica. |
| **Void Pattern (Patrón de Vacío)** | Si la IA no sabe algo, debe decir "No sé" en lugar de inventar. |

| **HITL (Humano presente)** | Siempre hay un humano revisando lo que la IA propone. |
| **UNCERTAINTY GATES** | Momentos donde la IA se detiene y te pide ayuda porque no está segura. |

---

## ⚠️ Consejos "Pro" para usar el Glosario

* **No inventes sinónimos:** Si algo es un "Ritual", no le digas "Hábito" o "Cacharro". Mantén la disciplina.
* **Si falta algo, dillo:** El lenguaje de MetodologIA evoluciona. Si necesitas una palabra nueva, pídela al Steward (Dueño del Glosario).

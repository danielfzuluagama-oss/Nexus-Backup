# MetodologIA | Success as a Service

> **Platform:** MetodologIA (Methodology + AI)
> **Domain:** https://metodologia.info
> **Version:** 2.0.0 (2026)

## Overview
This repository contains the source code for the MetodologIA website, a high-performance consultancy platform specializing in the convergence of Agile methodologies and Artificial Intelligence.

## Structure
- `/ruta`: The "Ruta de (R)Evolución" (Core Methodology).
- `/personas`: B2C Services (Bootcamps & Personal Growth).
- `/empresas`: B2B Services (Corporate Consulting).
- `/recursos`: Library of Assets (Free & Premium).
- `/nosotros`: Brand & Team components.
- `/estilos`: Modular CSS architecture.
- `/js`: Client-side logic (Icons, Modals).

## Technology Stack
- **Core**: HTML5 + Vanilla JS
- **Styling**: Tailwind CSS (via CDN/Production Build) + Custom CSS Variables
- **Icons**: Lucide (via CDN)
- **Fonts**: Google Fonts (Poppins, Montserrat)

## Key Files
- `index.html`: Main Gateway.
- `llms.txt`: Context file for AI Agents.
- `sitemap.xml`: SEO Map.

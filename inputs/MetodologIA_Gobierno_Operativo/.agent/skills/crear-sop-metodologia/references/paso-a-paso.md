# Paso a Paso: Implementación de SOPs Inmunes

## 1. Context Loading

- Cargar proceso L3 padre.
- Cargar plantillas de SOP autorizadas.

## 2. Secuencia Atómica

1. **TASK DECOMPOSITION:** Desglosar el proceso en subtareas de <15 mins.
2. **RITUAL MAPPING:** Vincular subtareas complejas a Rituales (Nivel Atómico) específicos.
3. **SLA ASSIGNMENT:** Definir tiempos máximos por paso.
4. **ERROR PROTOCOL:** Escribir el "Qué pasa si falla" para cada paso crítico.
5. **LINKING:** Asegurar que el SOP use paths absolutos para herramientas comunes.

## 3. Certificación
1. **WALKTHROUGH:** Realizar una ejecución de prueba (Dry Run).
2. **RELEASE:** Marcar el SOP como v1.0.0 en el changelog.

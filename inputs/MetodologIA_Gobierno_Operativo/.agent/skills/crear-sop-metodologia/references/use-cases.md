# Use Cases: Escenarios de Aplicación de SOPs

## 1. Actualización de Credenciales de API
**Escenario:** El token de n8n ha expirado y debe renovarse sin romper los workflows activos.
**Aplicación:** El SOP guía al operador paso a paso por la consola de n8n, exige la prueba de conexión y la actualización del archivo de secretos en el repo como evidencia final.

## 2. Publicación de Nueva Página en MetodologIA
**Escenario:** Un nuevo ritual ha sido aprobado y debe subirse al sitio web.
**Aplicación:** El SOP define los comandos de `git`, la estructura de carpetas `html/` y el ritual de verificación visual en el navegador.

## 3. Saneamiento de Lints en el Repositorio
**Escenario:** El skill de auditoría reporta 50+ errores de formato.
**Aplicación:** El SOP proporciona los comandos de `markdownlint`, las reglas de exclusión y el procedimiento de edición multi-archivo para corregir en masa.

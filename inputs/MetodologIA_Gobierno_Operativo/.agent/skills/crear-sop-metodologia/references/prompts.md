# Prompts: Aceleradores de SOPs

## 1. Prompt de Extracción de Procedimiento
> "Analiza el siguiente log de comandos de terminal: [LOG]. Genera un SOP numerado que replique exactamente el éxito obtenido, incluyendo los puntos de verificación de salida de cada comando."

## 2. Prompt de Simplificación Operativa
> "Revisa este SOP de 20 pasos. Identifica redundancias y agrúpalo en un máximo de 5 'Atomic Phases' de alta densidad. Asegura que no se pierda la integridad del procedimiento."

## 3. Prompt de Generación de Skills desde SOP
> "Convierte este SOP en una especificación de Meta-Protocolo para un nuevo skill. Define qué herramientas de terminal (`default_api`) se requieren para cada fase."

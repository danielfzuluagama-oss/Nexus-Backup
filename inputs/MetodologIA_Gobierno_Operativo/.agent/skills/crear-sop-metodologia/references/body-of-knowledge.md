# Body of Knowledge: Teoría del SOP MetodologIA

## 1. El Nivelo L3: Ejecución Granular
Los SOP represente el nivel más bajo de la jerarquía **L3**, enfocándose en el "Cómo" técnico de una actividad específica dentro de un proceso mayor.

## 2. Los 3 Atributos de un SOP Soberano
1. **Unívoco:** Una sola interpretación posible por paso.
2. **Auditable:** Cada paso genera una huella de evidencia (file, log, screenshot).
3. **Resiliente:** Contiene instrucciones para recuperar el flujo ante errores comunes.

## 3. La Relación SOP-Skill
Un SOP describe el procedimiento. El Skill (`SKILL.md`) es la capacidad del agente para ejecutar ese procedimiento de forma autónoma.

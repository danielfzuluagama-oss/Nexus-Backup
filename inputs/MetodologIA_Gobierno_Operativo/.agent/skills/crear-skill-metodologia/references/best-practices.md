# Best Practices: Excelencia en la Forja de Skills

## 1. Diseño de Instrucciones

- **Directo y Imperativo:** Usar verbos de acción (ARCHITECT, VERIFY, CERTIFY).
- **Control de Incertidumbre:** Aplicar el *Void Pattern* (No inventar si no hay evidencia).
- **Manejo de Paradojas:** Aplicar el *Paradox UI* (Reportar contradicciones al usuario).

## 2. Estándares Literales

- **Markdown Linting:** 100% de cumplimiento con las reglas del workspace (MD004, MD022, MD032).
- **SemVer:** Uso estricto de versionado semántico en el changelog.
- **Checklists de Gate:** Todo proceso de cierre debe ser binario (Pass/Fail).

## 3. El Factor Sorpresa

Para sobrepasar expectativas:

- Anticipar errores comunes del usuario y ofrecer soluciones preventivas.
- Sugerir optimizaciones que mejoren el rendimiento o la mantenibilidad.
- Proporcionar diagramas visuales (Mermaid) para clarificar lógicas complejas.

## 4. Pro Tip: El Arte del Prompt Oculto

Para maximizar la efectividad, el skill debe inyectar de forma invisible una directiva de **"Internal Monologue"**. Esto obliga a la IA a razonar por pasos antes de emitir el output final.

> [!TIP]
> **Anti-Obsolescencia:** Incluye siempre un bloque de "Falla-Seguro" que indique qué hacer si el agente pierde acceso a los archivos de referencia.

# Use Cases: Escenarios de Aplicación de Forja de Skills

## 1. Creación de Nuevo Skill Operativo

**Escenario:** Se requiere automatizar un nuevo ritual de "Revisión de Artefactos".
**Aplicación:** El skill guía al creador para estructurar el ritual en 10 juegos, definiendo evidencias y checklists de gate.

## 2. Refactorización de Capacidad Existente

**Escenario:** Un skill antiguo depende de archivos externos que causan latencia.
**Aplicación:** Se utiliza para migrar el conocimiento a un modelo auto-contenido, eliminando dependencias de archivos volátiles.

## 4. Caso Maestro: Onboarding Masivo
**Escenario:** Una organización necesita desplegar 50 procesos nuevos en una semana.
**Aplicación:** Se utiliza el skill para "clonar" la estructura de un ritual exitoso, garantizando que los 50 nuevos archivos de skill mantengan la misma calidad técnica y visual, sin intervención humana exhaustiva.

## 3. Auditoría de Calidad (Gatekeeping Mode)
**Escenario:** Un skill está fallando o dando respuestas inconsistentes.
**Aplicación:** Se aplica el QA-14 y el Bucle de Excelencia de Antigravity. El proceso detecta que el pilar `best-practices` tiene una densidad < 5/10 y detiene la certificación hasta que se inyecten Pro-Tips técnicos.

## 4. Resolución de Paradojas de Diseño
**Escenario:** El usuario solicita una capacidad que contradice los principios de MetodologIA (ej. skill centralizado vs modular).
**Aplicación:** El skill detecta la contradicción (Paradox UI) y, en lugar de obedecer ciegamente, presenta un análisis de riesgos y propone un diseño híbrido que protege la escalabilidad del sistema.

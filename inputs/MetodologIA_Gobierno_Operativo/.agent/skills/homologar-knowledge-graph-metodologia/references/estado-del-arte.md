# Estado del Arte: Armonización de Arquitecturas Visuales

## 1. La Deuda Técnica en Grafos
A medida que un ecosistema de skills crece, la fragmentación visual (diferentes estilos de Mermaid, diferentes niveles de detalle) se convierte en "Ruido de Pantalla". La homologación es el proceso de reducir la entropía visual para maximizar el reconocimiento de patrones.

## 2. El Estándar "Sovereign UI"
MetodologIA utiliza un set limitado de colores y formas en Mermaid:
- **Azul (#0047AB):** Intenciones y Estrategia (L1).
- **Oro (#D4AF37):** Skills y Protocolos (L3).
- **Gris (#333):** Evidencia y Archivos (L4).

## 3. Homologación como Gate de Calidad
Un skill no se considera "Certificado" si su grafo de conocimiento no ha sido pasado por el filtro de homologación visual.

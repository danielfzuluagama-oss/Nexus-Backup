# Best Practices: Homologación sin Fricción

## 1. Auditoría antes de Edición
No cambies la lógica del grafo original a menos que sea para corregir un error de dependencia flagrante. La homologación se enfoca en la **Presentación**.

## 2. Consistencia de Claves
Asegúrate de que las `classDef` sean idénticas en todos los archivos. Esto permite que el usuario reconozca los colores instantáneamente en cualquier parte del repositorio.

## 3. Versionamiento de Estilos
Cuando el estándar visual de MetodologIA evolucione, usa este skill para actualizar todos los archivos masivamente en un solo ritual de "Refactor Visual".

# Body of Knowledge: Semántica Visual en MetodologIA

## 1. El Lenguaje de las Formas
- **Círculos/Óvalos (()):** Triggers externos o estados de inicio.
- **Rectángulos ([]):** Acciones atómicas o skills.
- **Rombos ({}):** Gates de decisión o auditorías.
- **Rectángulos de Doble Borde ([[]]):** Evidencia física o activos soberanos.

## 2. Jerarquía de Colores (The Atomic Trinity)
- **Primary (Blue):** Intención estratégica. El "Por qué" se activa.
- **Accent (Gold):** El motor operativo. El "Cómo" se ejecuta.
- **Neutral (Grey):** El residuo sólido. El "Qué" se entrega.

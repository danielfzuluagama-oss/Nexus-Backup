# Use Cases: Escenarios de Ejecución de Rituales

## 1. Sincronización Semanal de Gobierno
**Escenario:** El Steward de Coherencia necesita revisar el estado de los Skills del repositorio.
**Aplicación:** El ritual utiliza el skill de auditoría para generar el reporte de brechas y toma decisiones sobre qué skills priorizar para el siguiente sprint.

## 2. Ritual de Emergencia (Incident Response)
**Escenario:** Se detecta una inconsistencia crítica en el nivel L0 que rompe la carga de skills.
**Aplicación:** Se activa un ritual ad-hoc para declarar el nuevo estándar y ejecutar el saneamiento masivo de archivos.

## 3. Ritual de Cierre de Mes (Performance Review)
**Escenario:** Revisión de las métricas Lagging de eficiencia operativa.
**Aplicación:** Comparativa entre el tiempo de forjado de skills v1 vs v2 y ajuste de los aceleradores GenAI en el pilar BoK.

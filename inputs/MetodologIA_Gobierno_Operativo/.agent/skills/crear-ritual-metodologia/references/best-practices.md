# Best Practices: Diseño de Rituales Síncronos

## 1. El Ritual "Pre-Flight"
Cada ritual debe ser precedido por un escaneo automático de las métricas Leading. El facilitador llega con el diagnóstico ya hecho por la IA.

## 2. Salida Estructurada Obligatoria
Un ritual sin una actualización en la Bitácora Operativa L4 es un ritual que no ocurrió. El output debe ser un log accionable.

## 3. Manejo de Bloqueos
Si una decisión no puede tomarse por falta de datos, el ritual debe disparar automáticamente un proceso de "Forjado de Datos" (Data Forging) con un responsable asignado.

> [!IMPORTANT]
> **Silencio Operativo:** Si todas las métricas están en verde y no hay riesgos detectados, el ritual debe cancelarse para preservar el tiempo ejecutivo.

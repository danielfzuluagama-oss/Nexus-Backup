Guía de Facilitación — Value Proposition Design

“Un canvas no es un poster para la pared. Es una herramienta de conversación estratégica. Úsalo para alinear a tu equipo, testear hipótesis, y evolucionar tu propuesta de valor con evidencia real de clientes.”

Metodología de Facilitación en 5 Pasos

01

Seleccionar el Segmento

Elige UN segmento específico a la vez. No mezcles B2C con B2B en la misma sesión.

  • → Para MetodologIA: iniciar con P1 (Profesional en Transición) — mayor volumen y claridad de jobs
  • → B2B: iniciar con E1 (Small Business) — ciclo de venta más corto, feedback más rápido
  • → Prepara sticky notes de 3 colores: azul (jobs), rojo (pains), verde (gains)
02

Mapear el Customer Profile (Derecha)

Siempre empieza por el cliente, nunca por tu solución. Dedica 60% del tiempo a este lado.

  • → Jobs: “¿Qué tareas intenta completar tu cliente?” — cubrir funcionales, sociales, emocionales
  • → Pains: “¿Qué le frustra? ¿Qué riesgos teme? ¿Qué le resulta demasiado costoso?”
  • → Gains: “¿Qué resultado mínimo espera? ¿Qué excedería sus expectativas?”
  • → Regla: mínimo 5 items por zona, máximo 10. Calidad sobre cantidad
03

Priorizar por Importancia

No todo tiene el mismo peso. Osterwalder usa una escala de 3 niveles:

  • → Esencial: Sin esto no hay propuesta viable. Bloquea el progreso del cliente
  • → Importante: Mejora significativa pero el cliente puede avanzar sin ello
  • → Nice-to-have: Diferenciador delightful pero no crítico
  • → Ejercicio: dar 3 votos a cada participante para los items más críticos
04

Diseñar el Value Map (Izquierda)

Ahora sí: ¿qué ofreces para resolver lo que descubriste en el lado derecho?

  • → Productos/Servicios: Lista lo que ofreces — tangible e intangible
  • → Pain Relievers: Para cada dolor priorizado, ¿cómo lo alivia tu oferta?
  • → Gain Creators: Para cada ganancia priorizada, ¿cómo la crea tu oferta?
  • → Para MetodologIA: el diferenciador es el Modelo de Soberanía Digital
05

Evaluar el Fit

Conecta las líneas entre el lado izquierdo y derecho. Busca gaps y huérfanos.

  • → Fit fuerte: Cada dolor esencial tiene al menos un reliever directo
  • → Gap: Dolor esencial sin reliever = oportunidad crítica o riesgo
  • → Huérfano: Reliever sin dolor correspondiente = posible waste
  • → Objetivo: 100% de cobertura en Esenciales, >80% en Importantes
  • → MetodologIA B2C: 92% fit. B2B: 88% — governance E3 necesita trabajo

# Inputs — Pristino Bot Prototype

Deposit your prototype materials here before running the IIKit pipeline.

## Structure

```
inputs/
  prototype/       — Source code, scripts, bot logic
  docs/            — PRDs, briefs, descriptions, screenshots
  references/      — External APIs, integrations, examples
  constraints/     — Non-functional requirements, compliance, limits
```

## Workflow

1. Add your Pristino Bot prototype files to the appropriate subfolder
2. Run `tessl install tessl-labs/intent-integrity-kit` (if not already installed)
3. Start the IIKit pipeline: `/iikit-00-constitution` or `/iikit-01-specify`

## What to include

- **prototype/**: Any existing code, scripts, prompts, agent definitions, or bot logic
- **docs/**: Product vision, user stories, feature descriptions, mockups, screenshots
- **references/**: Third-party API docs, integration specs, example conversations
- **constraints/**: Performance targets, compliance rules, platform limits, budget

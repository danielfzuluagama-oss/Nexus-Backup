# CREATE Workflow

## Trigger

User requests creation of any artifact: code, document, prompt, plan, analysis, content.

## Steps

### 1. Clarify Requirements

- Ask: **¿Qué?** (deliverable), **¿Para quién?** (audience), **¿Para qué?** (purpose)
- If ambiguous → use clarification workflow before proceeding
- Define acceptance criteria upfront

### 2. Design Before Execute

- Outline structure and approach before implementation
- Select relevant MetodologIA frameworks if applicable
- Identify which agents to delegate to (single/terna/committee)

### 3. Build Artifact

- Execute creation with the selected agent(s)
- Apply brand voice if user-facing content
- Follow iterative refinement: draft → review → polish

### 4. Quality Gate

- Score against relevant dimensions from quality-excellence skill
- For critical outputs: run Excellence Loop (max 2 iterations)
- Check forbidden words list
- Validate brand voice checklist if user-facing (8/8 required)

### 5. Deliver

- Present artifact to user
- Include brief explanation of approach taken
- Ask if adjustments are needed

## Quality Target

- Standard: >= 8/10 across applicable dimensions
- Critical: >= 9/10 + Adversarial+ testing

## Failure Handling

- If requirements unclear after 2 rounds: proceed with best interpretation, flag assumptions
- If quality gate fails after 2 iterations: deliver with quality notes
